# PLC 5K

پروژه PLC 5K شامل فایل‌های سخت‌افزار، نرم‌افزار و مستندات یک کنترلر صنعتی خانواده هافلر است. ساختار موجود نشان می‌دهد این محصول از برد اصلی مشترک `Main-V4.0.2` و برد نمایشگر/کلید `DIS-V3.8.4` استفاده می‌کند و فیرم‌ور اصلی آن در `Software/V4.6.0/welding_7segment` قرار دارد.

## ساختار پوشه‌ها

- `Docs`: دیتاشیت، فایل PDF معرفی محصول، عکس‌های محصول و دانش فنی پروژه.
- `Hardware/Main-V4.0.2`: شماتیک‌ها، PCB، کتابخانه داخلی، BOM و خروجی HTML برد اصلی.
- `Hardware/DIS-V3.8.4`: فایل‌های Altium مربوط به برد نمایشگر 5 کلید/سون‌سگمنت.
- `Software/V4.6.0/welding_7segment`: سورس Arduino/ESP32، فایل باینری و کتابخانه‌های مورد استفاده.
- `Software/libraries`: محل استاندارد کتابخانه‌های مشترک این پروژه؛ در حال حاضر خالی است.
- `Software/Program Addres.txt`: آدرس‌های فلش و یادداشت‌های پروگرام.

## مشخصات برداشت‌شده از مخزن

- پلتفرم نرم‌افزار: ESP32 با Arduino Core.
- نوع رابط کاربری: سون‌سگمنت و کلیدهای فیزیکی.
- کتابخانه‌های دیده‌شده در سورس: WebSockets، ArduinoJson، DS3231 و کتابخانه‌های کمکی پروژه.
- خروجی‌های build داخل پوشه نرم‌افزار وجود دارند و برای انتشار GitHub بهتر است فقط در صورت نیاز نگهداری شوند.

## نکات نگهداری

- تغییرات نرم‌افزاری جدید باید در نسخه مستقل داخل `Software` ثبت شود.
- فایل‌های Altium فقط توسط مسئول سخت‌افزار تغییر کنند.
- اگر کتابخانه‌ها قرار است مشترک باشند، از داخل سورس نسخه‌ها به `Software/libraries` منتقل و در README همان نسخه توضیح داده شوند.
- نام نسخه `V4.6.0` با الگوی بعضی پروژه‌های دیگر متفاوت است؛ استاندارد پیشنهادی مخزن `V.x.y.z` است.
