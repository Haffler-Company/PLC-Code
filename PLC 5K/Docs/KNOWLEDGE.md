# دانش فنی PLC 5K

این فایل خلاصه دانش فنی برداشت‌شده از ساختار فعلی پروژه PLC 5K است و باید با هر تغییر سخت‌افزار یا نرم‌افزار به‌روزرسانی شود.

## هدف محصول

PLC 5K یک کنترلر صنعتی با رابط سون‌سگمنت و کلیدهای فیزیکی است. ساختار نرم‌افزار `welding_7segment` نشان می‌دهد کاربرد اصلی آن در کنترل فرایندهای جوش یا فرایندهای مشابه با تنظیمات عددی، تایمرها و خروجی‌های مرحله‌ای است.

## سخت‌افزار

- برد اصلی: `Hardware/Main-V4.0.2`
- برد نمایشگر: `Hardware/DIS-V3.8.4`
- فایل‌های مهم: شماتیک‌های `POWER`, `INPUTS`, `OUTPUTS`, `SSR`, `SENSOR`، فایل PCB، BOM و خروجی HTML.
- برای تحویل تولید، وجود BOM به‌روز، خروجی Gerber/NC Drill و PDF شماتیک توصیه می‌شود.

## نرم‌افزار

- نسخه اصلی موجود: `Software/V4.6.0/welding_7segment`
- پلتفرم: ESP32 با Arduino Core
- وابستگی‌های دیده‌شده: DS3231، ArduinoJson، WebSockets و کتابخانه‌های داخلی.
- خروجی باینری داخل نسخه موجود است، اما سورس باید مبنای اصلی توسعه باشد.

## پروگرام و فلش

آدرس‌های فلش در `Software/Program Addres.txt` و همچنین فایل‌های `Build/addres.txt` نسخه نرم‌افزار نگهداری شده‌اند. قبل از release باید آدرس‌های bootloader، partitions، firmware و data با نسخه واقعی build تطبیق داده شوند.

## موارد نیازمند تکمیل

- تکمیل README داخل نسخه نرم‌افزاری `V4.6.0`.
- انتقال یا مستندسازی کتابخانه‌های مشترک در `Software/libraries`.
- تولید خروجی PDF سخت‌افزار برای مشاهده بدون Altium.
- بررسی امنیت رمزهای پیش‌فرض در صورت public شدن مخزن.
