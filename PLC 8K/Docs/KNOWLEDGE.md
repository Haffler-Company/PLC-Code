# دانش فنی PLC 8K

این فایل دانش فنی فعلی PLC 8K را بر اساس ساختار پوشه‌ها، نام پروژه‌ها و فایل‌های موجود خلاصه می‌کند.

## هدف محصول

PLC 8K کنترلر صنعتی خانواده هافلر با نمایشگر کاراکتری و رابط کلیدی است. نام پروژه نرم‌افزاری `welding_cleaning` نشان می‌دهد این محصول برای کنترل فرایند جوش و تمیزکاری یا ماشین‌آلات مشابه استفاده شده است.

## سخت‌افزار

- برد اصلی: `Hardware/Main-V4.0.2`
- برد نمایشگر/رابط: `Hardware/DIS-V3.0.2`
- زیرماژول‌های سخت‌افزار نمایشگر شامل `DisPlay`, `Interface`, `main` و `top` هستند.
- فایل‌های BOM و خروجی‌های HTML در بخش‌های مختلف وجود دارند.

## نرم‌افزار

- نسخه موجود: `Software/V.2.7.0`
- نسخه استخراج‌شده اصلی: `Software/V.2.7.0/V.2.7.0/welding_cleaning`
- نسخه قدیمی: `Software/V.2.7.0/V.2.7.0 OLD/welding_cleaning`
- پلتفرم: ESP32 با Arduino Core
- وابستگی‌های دیده‌شده: DS3231، ArduinoJson، WebSockets و کتابخانه‌های پروژه.

## نکات مهم

- وجود فایل‌های `.rar` کنار نسخه استخراج‌شده باعث تکرار داده و افزایش حجم مخزن می‌شود.
- تودرتویی `V.2.7.0/V.2.7.0` خوانایی را کم می‌کند و بهتر است در اصلاح ساختاری آینده ساده شود.
- اگر نسخه OLD برای مقایسه لازم است، باید تفاوت آن با نسخه اصلی در README نوشته شود.

## موارد نیازمند تکمیل

- README مستقل برای نسخه نرم‌افزار و نسخه OLD.

- خروجی PDF شماتیک‌ها و فایل release قابل پروگرام.
