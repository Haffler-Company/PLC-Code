# PLC 8K

پروژه PLC 8K شامل طراحی سخت‌افزار و فیرم‌ور کنترلر صنعتی هافلر با نمایشگر کاراکتری و تعداد کلید/ورودی بیشتر نسبت به خانواده 5K است. ساختار فعلی شامل برد اصلی `Main-V4.0.2`، برد نمایشگر `DIS-V3.0.2` و نسخه نرم‌افزار `V.2.7.0` است.

## ساختار پوشه‌ها

- `Docs`: دیتاشیت، معرفی PDF، عکس محصول و فایل دانش فنی.
- `Hardware/Main-V4.0.2`: برد اصلی مشترک شامل شماتیک‌ها، PCB، BOM و خروجی ساخت.
- `Hardware/DIS-V3.0.2`: مجموعه برد نمایشگر و رابط کاربری، شامل زیرپوشه‌های `DisPlay`، `Interface`، `main` و `top`.
- `Software/V.2.7.0`: فایل‌های فشرده و نسخه استخراج‌شده فیرم‌ور.
- `Software/libraries`: محل استاندارد کتابخانه‌های مشترک؛ فعلاً خالی است.
- `Software/Program Addres.txt`: آدرس‌های فلش/پروگرام.

## مشخصات برداشت‌شده از مخزن

- پلتفرم نرم‌افزار: ESP32 با Arduino Core.
- نوع رابط: LCD کاراکتری/کلیدهای فیزیکی.
- فیرم‌ور شامل پوشه `welding_cleaning` است و نشان می‌دهد کاربرد اصلی در کنترل فرایندهای جوش و تمیزکاری تعریف شده است.
- دو آرشیو `V.2.7.0.rar` و `V.2.7.0 OLD.rar` کنار نسخه استخراج‌شده وجود دارد؛ این مورد باعث افزایش حجم و تکرار داده می‌شود.

## نکات نگهداری

- ساختار `Software/V.2.7.0/V.2.7.0/...` یک سطح تودرتوی اضافه دارد و در اصلاح ساختاری آینده بهتر است ساده شود.
- نسخه قدیمی باید با توضیح دقیق نگهداری شود یا به آرشیو خارج از شاخه اصلی منتقل شود.
- فایل‌های خروجی Altium و BOM باید بعد از هر تغییر سخت‌افزار به‌روزرسانی شوند.
