## RELEASE CHECKLIST — Welding Single Head Firmware (ESP32-S3 / ST7796 / GT911)

### Phase 1: Safety & Failsafe (ایمنی صلب صنعتی زیمنس) ✅
- [x] خروجی‌های رله اکتیو-LOW (SSR_1=15, TABLE=16, PRESS_LEFT=42, PRESS_RIGHT=39, ELEMENT=48, SHABLON=40, ZARBEH1=35, ZARBEH2=36) قبل از کانفیگ `pinMode(OUTPUT)` در وضعیت `HIGH` تنظیم شده‌اند (ضد استارت ناخواسته در بوت).
- [x] قطع خودکار المنت در دمای بالای ۲۶۵ درجه سانتی‌گراد و محافظت در برابر قطع سنسور یا مقدار `NaN` روی درایور MAX6675.
- [x] تایم‌اوت محافظتی المنت حرارتی: در صورت گرم نشدن بیش از ۱۲۰ ثانیه، خطای هیتر صادر و SSR قطع می‌شود.
- [x] اینترلاک فیزیکی اتو: پیشروی جک المنت (ELEMENT) **هرگز** بدون فعال بودن هر دو پرس چپ و راست (PRESS_LEFT + PRESS_RIGHT) صورت نمی‌گیرد.
- [x] پاسخ فوق‌سریع به استپ قارچی (E-Stop روی GPIO 3) در کمتر از ۲۰ میلی‌ثانیه با قطع کامل تمامی خروجی‌ها.
- [x] مهار دترمینیسم جک‌ها: کلیه حرکات پنوماتیک با سنسورهای فیزیکی آنالوگ و تایم‌اوت ۷۰۰۰ میلی‌ثانیه‌ای (`SENSOR_TIMEOUT_MS`) کنترل می‌شوند.

### Phase 2: GT911 Touch & Display Performance (سرعت نمایشگر و تاچ اپل) ✅
- [x] پاکسازی بدون استثنای رجیستر `0x814E` بعد از هر چرخه خواندن تاچ GT911 (ضد فریز تاچ خازنی).
- [x] ایزولاسیون کامل دو هسته: رندرینگ رابط کاربری LVGL منحصراً روی Core 1 و شبکه/وب‌پورتال روی Core 0.
- [x] رعایت قانون به‌روزرسانی Dirty-Driven: به‌روزرسانی ویجت‌ها فقط در صورت تغییر مقدار نسبت به `s_last_*`.
- [x] قانون سایه صفر: `lv_obj_set_style_shadow_width(obj, 0, 0)` روی کلیه عناصر UI برای تضمین نرخ فریم بالای ۵۰FPS.
- [x] عدم تخصیص حافظه پویا (malloc/free) در حلقه‌های پریودیک و تسک‌های کنترل سیکل جوش.

### Phase 3: Warranty, Lease & Day-Lock 5-Stage (گارانتی و قفل کارخانه‌ای) ✅
- [x] مهلت تست ۱۵ دقیقه‌ای در زمان بوت برای دستگاه‌های فعال‌نشده؛ پس از پایان مهلت، اتو و سیکل جوش قفل می‌شوند.
- [x] کد اختصاصی ۱۱ رقمی مشتری بر پایه مک‌آدرس سخت‌افزاری و الگوریتم چکسام ریاضی Luhn.
- [x] فرم ثبت مشخصات خریدار (نام، شهر، شماره موبایل با نرمال‌سازی +98) و ارسال پیامک به سرور/مدیر کارخانه.
- [x] صف آفلاین پیامک: در صورت نبود اینترنت، گارانتی ثبت موقت شده و به محض اتصال Wi-Fi پیامک مخابره می‌شود.
- [x] معماری ۵ مرحله‌ای قفل اقساطی روزانه (Day-Lock) با الگوریتم چالش-پاسخ و ضد دستکاری ساعت سخت‌افزاری DS3231.

### Phase 4: Zero-Lag High-Speed OTA Engine (موتور آپدیت پرسرعت هافلر) ✅
- [x] پیش‌پاکسازی پارتیشن غیرفعال فلش (Pre-Erase در بلوک‌های ۶۴ کیلوبایتی) در ثانیه ۵ بوت و هنگام اتصال Wi-Fi.
- [x] تضمین فلش تمیز: سوکت دانلود هرگز در حین پاکسازی باز نمی‌شود تا استال SPI و افت پکت رخ ندهد.
- [x] دور زدن پاکسازی مجدد با `need_erase=false` در فراخوانی `esp_ota_begin`.
- [x] بهینه‌سازی شبکه: سوکت با بافر ۳۲KB/۶۴KB، `WIFI_PS_NONE`، `TCP_NODELAY` و تجمیع داده‌ها در چانک‌های ۸KB.

### Phase 5: WebApp & Telemetry (وب‌اپلیکیشن کارگاهی و تله‌متری) ✅
- [x] فایل‌های فرانت‌اند وب‌اپ در قالب GZIP فشرده درون فایل‌سیستم SPIFFS تعبیه شده‌اند.
- [x] مانیتورینگ بلادرنگ سنسورها، شمارنده جوشکاری و دمای اتو از طریق WebSocket و REST API روی Core 0.
- [x] تنظیمات کامل Wi-Fi (حالت AP و Station) از طریق صفحه پیکربندی وب‌اپ.

### Phase 6: Build Verification & Release Artifacts (بیلد کارخانه‌ای و پکیج انتشار) ✅

- [x] پاس شدن آزمون‌های لینتر ایمنی زیمنس و ارگونومی اپل (`haffler_safety_linter.py` بدون خطای بحرانی).
