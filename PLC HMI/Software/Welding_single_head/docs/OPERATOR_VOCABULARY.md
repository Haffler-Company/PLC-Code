# واژه‌نامه تخصصی اپراتوری و کارگاهی (Operator & Workshop Vocabulary)

این سند، مرجع یکتای معانی اصطلاحات کارگاهی و زبان محاوره‌ای کاربر در صنعت تولید درب و پنجره UPVC و تطبیق دقیق آن‌ها با مفاهیم سورس‌کد و متغیرهای فریم‌ور HMI است.

---

## ۱. جدول واژگان فرآیند و ماشین (Process & Machine Terms)

| اصطلاح کارگاهی کاربر | معادل انگلیسی / صنعتی | متغیر یا مفهوم متناظر در کد | شرح عملیاتی در دستگاه |
|---|---|---|---|
| **لنگه** | Window Sash / Frame Unit | `completed_weld_cycles_in_frame`, `frame_numbers` | یک پنجره مستطیلی کامل UPVC که از ۴ گوشه جوش تشکیل شده است. دستگاه جوش تک‌سر در هر چرخه ۱ گوشه (۱/۴ لنگه) را جوش می‌دهد. پس از هر ۴ چرخه، یک لنگه کامل ثبت می‌شود. |
| **چهارچوب / فریم** | Outer Frame | `total_frame_numbers` | قاب ثابت دور پنجره که در دیوار نصب می‌شود (متفاوت با لنگه بازشو). |
| **پروفیل** | UPVC Profile | Profile Settings / Recipe | شاخه‌های پلاستیکی اکسترود شده UPVC که دو سر فارسی‌بُر شده آن‌ها با زاویه ۴۵ یا ۹۰ درجه ذوب و جوش می‌خورند. |
| **المنت / هیتر** | Heating Plate / Mirror | `ELEMENT` (GPIO48), `SSR_1` (GPIO15) | صفحه داغ آلومینیومی با روکش پارچه تفلون که دمای آن حدود ۲۴۰–۲۶۰ درجه است و بین دو پروفیل قرار می‌گیرد. |
| **فک / پرس (چپ و راست)** | Clamping Jacks | `PRESS_LEFT` (GPIO42), `PRESS_RIGHT` (GPIO39) | جک‌های پنوماتیک عمودی که شاخه‌های پروفیل را روی میز محکم فشار می‌دهند تا تکان نخورند. |
| **شابلون صفر** | Zero Positioning Shablon | `SHABLON` (GPIO40) | زبانه تنظیم موقعیت اولیه که بالا می‌آید تا اپراتور نوک پروفیل‌ها را به آن بچسباند و موقعیت دقیق جوش تنظیم شود. |
| **صفحه / میز** | Moving Welding Table | `TABLE` (GPIO16) | میز متحرک افقی که پروفیل‌ها را ابتدا به شابلون، سپس به سمت هیتر و در نهایت به یکدیگر می‌فشارد. |
| **ذوب / زمان ذوب** | Melting Dwell Time | `josh_time`, `get_var_welding_time()`, `WT1..WT8` | مرحله‌ای که پروفیل‌ها به المنت داغ چسبانده می‌شوند تا لبه آن‌ها نرم و مذاب شود (معمولاً ۱۰ تا ۳۰ ثانیه). |
| **فشار** | Compression / Fusion Phase | Step 11 (`TABLE ON` after element retracted) | مرحله خروج سریع المنت و به هم فشردن دو لبه مذاب پروفیل‌ها با فشار بالای پنوماتیک. |
| **خنک‌کاری** | Cooling Dwell Time | `cool_time`, `get_var_cooling_time()`, `CT1..CT8` | مرحله نگه‌داشتن پروفیل‌ها زیر فشار فک‌ها تا پلیمر سفت شده و ساختار جوش مستحکم شود (معمولاً ۱۵ تا ۴۰ ثانیه). |
| **ضربه خردکن / تیغه** | Knive / Burrs Cleaner | `ZARBEH1` (GPIO35), `ZARBEH2` (GPIO36) | تیغه‌های متحرکی که در حین خنک‌کاری فعال می‌شوند تا گوشه پلیسه و ضایعات جوش را بتراشند یا بشکنند. |
| **پلیسه** | Welding Burr / Flash | Burr material cleaned by Zarbeh | زائده پلاستیک مذاب که بر اثر فشار جوشکاری از درز اتصال بیرون می‌زند. |
| **دمای هدف** | Target Temperature | `get_var_element_temperature_target()`, `TT1..TT8` | دمای تنظیمی صفحه هیتر (معمولاً ۲۴۵–۲۵۵ درجه سانتی‌گراد). |
| **پدال** | Foot Pedal Switch | `PEDAL` (GPIO7), `pedal_operation()` | میکروسوئیچ پایی که اپراتور برای پیشروی گام‌به‌گام یا استارت چرخه جوش فشار می‌دهد. |
| **رسیپی / فرمول** | User Profile / Recipe | `SelectedUser` (1..8), `WT[i]`, `CT[i]`, `TT[i]` | ذخیره ۸ پروفایل مختلف کاری متناسب با مارک‌های گوناگون پروفیل (وین‌تک، ویستابست، هافمن و...). |

## ۲. جدول اصطلاحات الکترونیک و کنترل (Electronics & Sensors)

| اصطلاح | معادل فنی | در کد / شماتیک | نکته کلیدی |
|---|---|---|---|
| **SSR** | Solid State Relay | `SSR_1` (GPIO15) | رله الکترونیکی بدون صدا برای کنترل برق ۲۲۰ ولت المنت (منطق Active LOW: مقدار 0 یعنی روشن). |
| **ترموکوپل** | K-Type Thermocouple | `MAX6675` (SPI) | سنسور خواندن دمای لحظه‌ای المنت تا دمای ۱۰۰۰ درجه. |
| **آفست دما** | Temperature Calibration Offset | `get_var_temp_offset()` | مقدار تصحیح دمای خوانده شده برای تطبیق با دماسنج کالیبره کارگاهی. |
| **استوپ اضطراری / قارچی** | Emergency Stop (E-Stop) | `EMERGENCY` (GPIO3) | کلید قرمز قارچی بزرگ روی بدنه که فشار دادن آن باید تمام خروجی‌ها را در صفر ثانیه قطع کند. |
| **سنسور رفت / برگشت** | Cylinder Position Sensors | `SENSOR_ELEMENT`, `SENSOR_TABLE`, `SENSOR_SHABLON` | سنسورهای مغناطیسی جک‌ها که با تقسیم ولتاژ مقاومتی (آنالوگ) موقعیت باز/بسته بودن را گزارش می‌دهند. |
| **قفل دستگاه** | Machine Safety Lock | `g_device_locked` | قفل نرم‌افزاری دستگاه جهت جلوگیری از فرمان پدال هنگام ارور یا تنظیمات. |

## ۳. دستورالعمل درک منظور کاربر برای ایجنت‌ها

- وقتی کاربر می‌گوید: **«زمان ذوب کمه»** ➔ به معنی افزایش متغیر `WeldingTime` در NVS رسیپی فعال است.
- وقتی کاربر می‌گوید: **«فک راست شل می‌گیره / دیر عمل می‌کنه»** ➔ به معنی بررسی زمان حرکت `press_right_raft` در تنظیمات جک‌ها است.
- وقتی کاربر می‌گوید: **«پلیسه‌گیری رو عقب بنداز»** ➔ به معنی تنظیم تایمر فعال‌سازی `ZARBEH1` / `ZARBEH2` در حین خنک‌کاری است.
- وقتی کاربر می‌گوید: **«شمارنده رو صفر کن»** ➔ به معنی ریست کردن `frame_numbers` در NVS و UI است.
