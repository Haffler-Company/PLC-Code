# کتابچه مشخصات فنی سیستم طراحی صنعتی و استانداردهای ریاضی LVGL هافلر
## Haffler Industrial HMI Design System & Mathematical LVGL Specifications
### ASTIAJ CM-700 / ICE CREAM PLC HMI — Screen Resolution: 480x320

---

## ۱. منشور خطوط تراز مرزی و خط شاقول صفحه (Anchor Lines & Layout Geometry)

نمایشگر صنعتی هافلر با رزولوشن ۴۸۰×۳۲۰ پیکسل دارای یک شبکه مختصاتی بسیار صلب است:

```
0,0 ───────────────────────────────────────────────────────────── 480,0
│  x=8                                                    x=406 │ x=410..480
│  ┌──────────────────────────────────────────────────────────┐ │ ┌─────────┐
│  │                     نوار تیتر تب (Header)                 │ │ │ منوی F  │
│  │                     w = 398 px                           │ │ │ عمودی   │
│  ├────────────────────────────┬─────────────────────────────┤ │ │ F1..F6  │
│  │ ستون چپ (استپرها / کنترل)  │ ستون راست (کارت‌ها / مانیتور)│ │ │ w=70px  │
│  │ x=8, w=238 px             │ x=248, w=158 px             │ │ │         │
│  │ (پایان در x=246)          │ (پایان دقیق روی x=406)       │ │ │         │
│  ├────────────────────────────┴─────────────────────────────┤ │ │         │
│  │                نوار ابزار پایین (Bottom Toolbar)          │ │ │         │
│  │                y=268, h=42, محدوده x=8..406              │ │ │         │
│  └──────────────────────────────────────────────────────────┘ │ └─────────┘
0,320 ─────────────────────────────────────────────────────────── 480,320
```

### قوانین هندسی تخطی‌ناپذیر:
1. **مرز صلب x=406:** انتهای سمت راست نوار تیتر تب، کارت ستون راست و کلیدهای نوار ابزار پایین باید دقیقاً روی **`x=406`** بسته شوند. هرگونه کشیدگی تا `x=412` یا فراتر موجب تداخل بصری با منوی کلیدهای F1..F6 خواهد شد.
2. **حریم نوار ابزار پایین (y=268..310):** ارتفاع دکمه‌های نوار ابزار ۴۲ پیکسل است و حاشیه پایینی ۱۰ پیکسل از کف صفحه (`y=320`) دارد.

## ۲. فرمول ریاضی کانتینر استپرها (5-Stepper Ergonomics & Zero-Drop Layout)

برای جلوگیری از افتادگی ارقام و مهار بریدگی متون در هر ۳ زبان:

```c
/* ابعاد کلی کارت استپر */
int32_t card_x = 8;
int32_t card_w = 238; // ستون چپ
int32_t card_h = 40;  // ارتفاع متناسب ۵ کارت در فضای y=38..254

/* المان‌های تعاملی کنترل مقدار */
int32_t btn_minus_x = 4;
int32_t btn_w = 20;
int32_t val_w = 34;   // کادر ارقام (جاگیری اعداد تا ۳ رقم)
int32_t btn_h = 30;   // ارتفاع لمسی مطمئن
int32_t btn_y = (card_h - btn_h) / 2; // y=5 (تراز دقیق وسط عمودی)

int32_t val_x = btn_minus_x + btn_w + 2; // x=26
int32_t btn_plus_x = val_x + val_w + 2;   // x=62
int32_t ctrl_end_x = btn_plus_x + btn_w;  // x=82

/* حاشیه تنفس اپل و کادر عنوان */
int32_t lbl_x = ctrl_end_x + 16;          // x=98 (حداقل ۱۶px فاصله امن از کلید +)
int32_t max_title_w = card_w - lbl_x - 6; // w=134px برای عنوان
```

### اصول مهندسی استپر:
* **تراز ریاضی عدد:** کانتینر مقدار با زمینه روشن `#F1F5F9` و بوردر ۱px `#CBD5E1` و `pad_all = 0` ساخته شده و برچسب رقم با `lv_obj_center(lbl)` در مرکز قفل می‌شود.
* **گسترش کلیک:** هر دو کلید مثبت و منفی با `lv_obj_set_ext_click_area(btn, 6)` ارگونومی لمسی ۴۴ پیکسلی پیدا می‌کنند.

## ۳. فرمول ستون راست کارت ایمنی (Locked Safety Timers Card)

* **ابعاد کادر:** `pos = (248, 38)` و `size = (158, 216)` (لبه راست دقیقاً روی ۴۰۶).
* **بج قرمز بالا:**
  * ابعاد: `pos = (4, 4)` و `size = (150, 24)`.
  * استایل: زمینه `#FEF2F2`، بوردر `#FCA5A5`، متن `#DC2626`.
* **عنوان توضیحی فرعی:**
  * ابعاد: `pos = (4, 30)` و `size = (150, 32)` (ارتفاع ۳۲px جهت جاگیری امن دو سطر در انگلیسی و ترکی بدون افتادن روی خط جداکننده).
* **خط جداکننده افقی:** `pos = (4, 64)` و `size = (150, 1)` با رنگ `#E2E8F0`.
* **ردیف‌های ۴ گانه آیتم‌ها (y = 68, 104, 140, 176 با h = 34):**
  * کپسول مقدار در سمت چپ: `pos = (2, 6)` و `size = (44, 22)`.
  * برچسب پارامتر: در انگلیسی/ترکی چپ‌چین از `x=48` با عرض ۱۰۴ پیکسل؛ در فارسی راست‌چین با حاشیه امن ۴ پیکسل از دیواره راست.
