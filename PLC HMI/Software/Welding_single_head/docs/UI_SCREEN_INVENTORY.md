## ۲. لایه‌بندی و پنجره‌های شناور (Modal & Overlay Hierarchy)

1. **لایه پس‌زمینه (Base Screen):** صفحه فعال جاری از جدول بالا.
2. **لایه پنل‌های هشدار خطای جک (`jack_time_error_panel`):**
   - نمایش در زمان تایم‌اوت سنسور یا خطای حرکت جک با سایه استاندارد (حداکثر ۴ پیکسل طبق Apple HIG).
3. **لایه پنل آپدیت OTA (`g_ota_overlay`):**
   - نمایش درصد دانلود، سرعت KB/s و اعلان موفقیت آپدیت.
4. **لایه کیبورد و پین‌کد ادمین:**
   - کادر ورود رمز ۴ رقمی با دکمه‌های لمسی شفاف و محافظت در برابر بروت‌فورس.

## ۳. قوانین حیاتی رندر و تایپوگرافی (RTL vs LTR)

- **برچسب‌های متنی فارسی:**
  - باید حتماً ویژگی `lv_obj_set_style_base_dir(label, LV_BASE_DIR_RTL, 0)` داشته باشند و از فونت‌های استاندارد پروژه (`ui_font_kalameh_*` یا `ui_font_vazirmatn_*`) استفاده کنند.
- **مقادیر عددی و لاتین (دما، زمان، آدرس IP، نسخه):**
  - باید حتماً به صورت `LV_BASE_DIR_LTR` تنظیم شوند تا ارقام چپ‌به‌راست و بدون جابجایی کاراکتر نمایش داده شوند.
- **به‌روزرسانی با گارد تغییر (`if_changed`):**
  - هرگز `lv_label_set_text` یا استایل‌ها را بدون بررسی تغییر مقدار قبلی در حلقه تیک صفحه صدا نزنید:
    ```c
    // روش الزامی:
    static int last_temp = -999;
    int cur_temp = (int)get_var_element_temperature();
    if (cur_temp != last_temp) {
        lv_label_set_text_fmt(lbl_temp, "%d°C", cur_temp);
        last_temp = cur_temp;
    }
    ```
