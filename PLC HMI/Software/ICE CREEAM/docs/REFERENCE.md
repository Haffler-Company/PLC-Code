# مرجع مشخصات فنی سخت‌افزار و نرم‌افزار
## Technical Reference & Architecture Map

### ۱. نگاشت سخت‌افزاری (Hardware Baseline)

| ردیف | بخش سخت‌افزاری | مشخصات فنی و نگاشت پایه‌ها |
|---|---|---|
| ۱ | پردازنده مرکزی | ESP32-S3 N16R8 (دو هسته‌ای ۲۴۰MHz، فلش ۱۶MB، رم داخلی ۵۱۲KB، حافظه PSRAM ۸MB) |
| ۲ | نمایشگر گرافیکی | ال‌سی‌دی ۳.۵ اینچ ILI9488 روی گذرگاه SPI2 (MOSI: GPIO10, SCLK: GPIO12, CS: GPIO13, DC: GPIO14) |
| ۳ | تاچ و ساعت سخت‌افزاری | تاچ خازنی GT911 و آی‌سی ساعت RTC DS3231 روی I2C0 فرکانس ۴۰۰kHz (SDA: GPIO8, SCL: GPIO9) |
| ۴ | سنسورهای دما | دو کانال MAX6675 با رجیسترهای مستقیم (MISO: GPIO37, SCK: GPIO47, CS1 مخزن شیر: GPIO21, CS2 سیلندر: GPIO0) |
| ۵ | کتابخانه گرافیکی | LVGL نسخه ۹.۴ با بافر دوگانه DMA به حجم ۳۰KB و تعویض ۳۲ بیتی موازی بایت‌ها (SIMD Swap) |
| ۶ | خروجی‌های اصلی | کمپرسور کوچک GPIO16، کمپرسور بزرگ سیلندر GPIO42، موتور پارو GPIO39 (منطق Active-LOW: 0=ON, 1=OFF) |
| ۷ | خروجی‌های کمکی | پمپ کرم GPIO48، شیر باد لبه رنگی GPIO38 (SSR2)، پمپ ژله رینبو GPIO40، بازر GPIO45، رله ریست GPIO18 |
| ۸ | ورودی‌های اصلی اپراتور | میکروسوئیچ دسته جلو GPIO4، میکروسوئیچ کلاچ عقب GPIO5، کلید قارچی استپ GPIO3، کلید استارت GPIO7 (Active-LOW) |
| ۹ | ورودی‌های حفاظتی | سنسور القایی پولی GPIO6، کنترل‌بار موتور همزن GPIO15، کنترل‌بار کمپرسور GPIO17 |
| ۱۰ | حافظه پایدار | NVS فلش پایدار با تغییرسنج هوشمند (Skipping redundant writes جهت کاهش ۹۵٪ استهلاک فلش) |

> ⚠️ **مرجع نهایی:** فایل `main/project_config.h` تک‌منبع رسمی پین‌ها است.

### ۲. نگاشت ماژول‌های نرم‌افزاری (Software Map)

| مسیر فایل سورس | شرح وظایف مهندسی و مسئولیت در سیستم |
|---|---|
| `main/main.c` | راه‌اندازی سیستم، ماشین وضعیت PLC زیمنس، حلقه‌های کنترلی، تایمینگ و اینترلاک‌ها |
| `main/project_config.h` | نگاشت قطعی پین‌ها، پولاریته، ثوابت زمانی، اینترلاک‌های حرارتی و کلیدهای NVS |
| `main/day_lock_core.*` | موتور قفل روزشمار و اقساط، ضد دستکاری ساعت RTC، الگوریتم چالش-پاسخ و قفل نرم/سخت |
| `main/day_lock_storage.*` | ذخیره‌سازی اتمیک سوابق لایسنس، مراحل پرداخت و فلگ‌های امنیتی در NVS |
| `main/day_lock_ui.*` | رابط کاربری مودال دریافت رمز روزشمار، نمایش روزهای باقیمانده و اعلان وضعیت مراحل |
| `main/ota_update.*` | کلاینت OTA سرور هافلر، پارسر ۸ بخشی فراداده `lastfile`، نقشه اتصالات، و لاگ تجمعی |
| `main/panel_nav.*` | ناوبری ماتریس کلیدهای پنل فیزیکی، مدیریت فوکوس، و بنرهای اعلان Toast اپل با نوار تخلیه‌شونده |
| `main/ui/ui_lang.*` | سیستم بومی‌سازی سه‌زبانه (فارسی، انگلیسی، ترکی)، تغییر آنی زبان و تضمین Zero Tofu |
| `main/ui_resume.*` | بازیابی نامحسوس صفحه پس از کرش/ریست با حافظه کند بی‌درنگ RTC RAM (`RTC_NOINIT_ATTR`) |
| `main/serial_hmi.*` | پروتکل سریال امن دوطرفه با احراز هویت HMAC-SHA256 و استریم اسکرین‌شات از PSRAM |
| `main/max6675.*` | درایور ثبات‌های سریع دو کانال ترموکوپل تیپ K و تشخیص فوری قطعی سیم پراب |
| `main/fault_log.*` | حلقه ثبت ۱۰ خطای اخیر بر پایه استاندارد ISA-18.2 با زمان DS3231 در NVS |
| `main/extra_modes.*` | کنترل مدهای شستشو، تزریق لبه رنگی، رینبو، تخلیه پیوسته، و اینترلاک‌های ترمودینامیکی |
| `main/adc.*` | نمونه‌برداری آنالوگ و مانیتورینگ جریان مصرفی ترانسدیوسرها |
| `main/lcd_ili9488.*` | درایور موازی ال‌سی‌دی ILI9488 با خطوط DMA و شتاب‌بخشی ۳۲ بیتی بایت‌سوآپ |
| `main/gt911.*`, `i2c_bus.*` | درایور تاچ اسکرین خازنی با فیلتر سه‌مرحله‌ای (Deadband، اسپایک و میانگین متحرک) |
| `main/ds3231.*` | درایور ساعت سخت‌افزاری دقیق I2C، مبدل تقویم جلالی، و همگام‌سازی ساعت سیستم POSIX |
| `main/buzzer.*` | درایور پیزوالکتریک غیرمسدودکننده با الگوهای صوتی متنوع و قطع اضطراری آنی |
| `main/webportal.*` | وب‌سرور داخلی HTTP، داشبورد تله‌متری موبایل، سیستم دخل و حسابداری، و صدور فاکتور تصویری |
| `main/wifi.*` | مدیر وای‌فای در حالت دوگانه AP+STA با قابلیت اسکن شبکه‌ها و اتصال پایدار |
| `main/timer.*` | هوک تایمر قطعی ۱ هرتزی سیستم و اعمال وظایف پس‌زمینه |
| `main/storage.*` | توابع لایه دسترسی NVS با اعتبارسنجی تغییرات قبل از نوشتن روی فلش |
| `main/ui/` | صفحات، تم دارک اپل، دکمه‌های Slate، فونت‌های یکان با فال‌بک مونتسرات |
| `main/ui_refresh.*` | مدیریت رندرینگ مبتنی بر تغییر (Dirty-driven) جهت حذف بار پردازشی فریم‌های ثابت |

### ۳. ابزارهای توسعه و ممیزی پایتون (`tools/`)

| نام ابزار | کاربرد عملیاتی |
|---|---|
| `tools/haffler_day_lock_keygen.py` | ابزار کارخانه‌ای تولید پاسخ چالش ۵ رقمی دستگاه، رمزهای مراحل اقساط و ریست اضطراری |

| `tools/send_sms.py` | ابزار ارسال پیامک، استعلام اعتبار و مانیتورینگ خطوط SMS.IR |
