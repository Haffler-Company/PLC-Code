# ابزار اسکرین‌شات صفحه HMI — پروتکل آسنکرون بدون وقفه (Zero-Lag Snapshot)

ابزار فوق سریع دریافت عکس واقعی فریم‌بافر صفحه نمایشگر با نرخ تبادل **۹۲۱,۶۰۰ باود** و کپی مستقیم در حافظه (بدون قفل کردن یا هنگ کردن صفحه HMI).

## مزایا و معماری جدید
1. **Zero UI Freeze:** فرآیند عکس‌برداری در حافظه PSRAM جمع‌آوری شده و بلافاصله به تسک پس‌زمینه محول می‌شود و نخ LVGL حتی برای ۱ فریم هم قفل نمی‌شود.
2. **ارسال در تسک پس‌زمینه (Core 0 Background Worker):** تسک اختصاصی `ShotWorker` داده‌های سریال را به صورت آسنکرون استریم می‌کند.
3. **سرعت ۳ ثانیه‌ای:** با نرخ ۹۲۱,۶۰۰ باود کل فریم در ۳ الی ۴ ثانیه منتقل می‌شود.

## پیش‌نیازها (سمت PC)

```powershell
pip install pyserial pillow
```

## نحوه استفاده

```powershell
# تشخیص خودکار پورت CP210x و گرفتن عکس فوری
python tools/hmi_screenshot.py

# با مشخص کردن پورت دلخواه
python tools/hmi_screenshot.py --port COM4 --baud 921600 --out screenshot.png
```
