# سند جامع مهندسی و مشخصات فنی دستگاه کپی‌روتر هافلر
## Haffler Copy Router & Triple-Drill Machine Master Specification
### مدل: HAFFLER CR-600 / برد کنترلر ETV3A (ESP32-S3 N16R8)

---

## ۱. مشخصات عمومی و مکانیسم ماشین (Machine Architecture)

دستگاه کپی‌روتر هافلر جهت فرزکاری دقیق جای قفل، دستگیره، لولا و شیار تخلیه آب‌باران در پروفیل‌های آلومینیوم و UPVC طراحی شده است.

* **دو اسپیندل قدرتمند پرسرعت (Dual High-Speed Spindles):**
  - **موتور ۱ (Vertical Spindle):** اسپیندل عمودی پرسرعت (۱۲,۰۰۰ تا ۱۸,۰۰۰ دور بر دقیقه) مجهز به فرز انگشتی تنگستن کارباید تک‌پر و انگشتی شابلون (Stylus Pin) چندقطری (۴mm، ۶mm، ۸mm).
  - **موتور ۲ (Triple Gearbox Drilling Motor):** گیربکس افقی سه مته جهت سوراخ‌کاری همزمان ۳ سوراخ استاندارد دستگیره (فاصله آکس تا آکس معمولاً ۲۱.۵mm یا ۲۲mm).
* **سیستم خنک‌کاری مه آب و صابون (Micro-Mist Coolant):**
  - پاشش مداوم مه مایع خنک‌کننده در برش آلومینیوم جهت افزایش طول عمر مته و کیفیت سطح برش بدون چسبیدن پلیسه.
* **شابلون‌های پیش‌فرض قابل انتخاب:**
  - شابلون قفل اسپانیولت، شابلون دستگیره، شابلون آب‌رو مخفی و کتیبه.

## ۲. توالی کارکرد و ماشین وضعیت (Operating FSM Sequence)

```
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│ ۱. مهار پروفیل   │ ──> │ ۲. استارت اسپیندل│ ──> │ ۳. هدایت شابلون  │ ──> │ ۴. سوراخ‌کاری ۳  │
│ (Pneumatic Clamp)│     │ (Spin-up 15,000) │     │ (Routing Cycle)  │     │ مته افقی (Triple)│
└──────────────────┘     └──────────────────┘     └──────────────────┘     └──────────────────┘
```

1. **فاز ۱ - کلمپ قطعه کار:**
   - فشردن پدال پایی؛ جک‌های پنوماتیک افقی پروفیل را مهار می‌کنند. سنسور فشار باد بالای ۶ بار را تایید می‌کند.
2. **فاز ۲ - استارت اسپیندل و خنک‌کننده:**
   - اپراتور شستی فرزکاری را می‌فشارد. کنتاکتور اسپیندل عمودی جذب شده و شیر اسپری مه آب و صابون باز می‌شود.
   - تاخیر ۲ ثانیه‌ای برای رسیدن اسپیندل به دور نامی پیش از ورود ابزار به قطعه کار.
3. **فاز ۳ - فرزکاری با کپی‌شابلون:**
   - پین راهنما داخل الگوی شابلون حرکت کرده و شیار مورد نظر را ایجاد می‌کند.
4. **فاز ۴ - سیکل سوراخ‌کاری ۳ مته افقی (در صورت نیاز):**
   - اهرم هیدروپنوماتیک افقی به جلو رانده شده و سه سوراخ دستگیره را با سرعت یکنواخت ایجاد می‌کند.
   - میکروسوئیچ انتهای کورس بازگشت مته‌ها را به سیستم اعلام می‌کند.

## ۳. اینترلاک‌های ایمنی سخت‌افزاری

1. **حفاظت حرارتی و کنترل‌بار اسپیندل (Thermal Overload):**
   - پایش مداوم کلید حرارتی بی‌متال؛ اضافه جریان اسپیندل در کمتر از ۱۰۰ms موتور را قطع و آلارم تریپ صادر می‌کند.
2. **اینترلاک فشار باد:** در صورت افت فشار باد، استارت اسپیندل‌ها مسدود می‌شود تا قطعه پرتاب نگردد.
3. **ایمنی لحظه صفر بوت (Boot Clamping):** سطح رله‌ها روی ۱ صلب می‌شود.
4. **ایزولاسیون ورودی‌ها و پورت سریال:** مهار پرش فانتوم و ممانعت از ریست تصادفی.
