HAFFLER INDUSTRIAL CONTROLLER
Program: firmware_bakery_changir
Title: چانه‌گیر و گردکن خمیر نانوایی (Bakery Dough Divider & Rounder)
Version: V.1.1.0

[POWER]
N = نول
L = فاز 220 ولت
PE = ارت محافظ بدنه

[INPUTS]
IN1 = سنسور موقعیت هوم پیستون (Piston Home Sensor - GPIO 7)
IN2 = سنسور موقعیت هوم قیف (Funnel Home Sensor - GPIO 3)
IN3 = صفحه کلید کارگاهی پنل F (Keypad F Panel - GPIO 1)
IN4 = صفحه کلید کارگاهی پنل M (Keypad M Panel - GPIO 2)
M0 = ورودی/خروجی کمکی 0
M1 = ورودی/خروجی کمکی 1
M2 = ورودی/خروجی کمکی 2
M3 = ورودی/خروجی کمکی 3
M4 = ورودی/خروجی کمکی 4
M5 = ورودی/خروجی کمکی 5
M6 = ورودی/خروجی کمکی 6
M7 = ورودی/خروجی کمکی 7

[OUTPUTS]
OUT1 = رله موتور برش پیستون (Piston Motor Relay - GPIO 36)
OUT2 = رله موتور تغذیه قیف (Funnel Motor Relay - GPIO 42)
OUT3 = فرمان حرکت رو به جلو اینورتر (Inverter Forward FWD - GPIO 39)
OUT4 = فرمان حرکت معکوس اینورتر (Inverter Reverse REV - GPIO 48)
M0 = خروجی/ورودی کمکی 0
M1 = خروجی/ورودی کمکی 1
M2 = خروجی/ورودی کمکی 2
M3 = خروجی/ورودی کمکی 3
M4 = خروجی/ورودی کمکی 4
M5 = خروجی/ورودی کمکی 5
M6 = خروجی/ورودی کمکی 6
M7 = خروجی/ورودی کمکی 7

[COMMUNICATION]
WiFi = اتصال به روتر کارگاه و پورتال محلی (192.168.4.1)
RS485/TTL = بدون اتصال
