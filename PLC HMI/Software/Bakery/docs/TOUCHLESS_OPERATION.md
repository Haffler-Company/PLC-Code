# راهنمای جامع و مشخصات کاربری ۱۰۰٪ بدون تاچ (Touchless Operation Specification)
## دستگاه چانه‌گیر و گردکن خمیر نانوایی هافلر (Haffler Industrial Bakery Dough Divider)

این مستند تشریح‌کننده کامل معماری، نحوه عملکرد و استانداردهای پیاده‌سازی کاربری بدون لمس صفحه (Touchless Mode) در سفت‌افزار چانه‌گیر هافلر است. در محیط‌های نانوایی و کارگاه‌های تولید نان به دلیل وجود گرد آرد، خمیر، دستکش‌های کارگری و رطوبت، اپراتور باید بتواند تمامی مراحل تنظیم، راه‌اندازی، تغییر دستور پخت و کالیبراسیون را **۱۰۰٪ بدون نیاز به لمس صفحه نمایشگر** و تنها از طریق ۱۰ کلید صنعتی جلو پنل و پدال پایی انجام دهد.

---

## ۱. نمای پنل و افزونگی کامل ورودی‌ها (Dual-Input Redundancy)

سیستم کنترل بر مبنای استاندارد صنعتی زیمنس مجهز به افزونگی کامل ورودی‌هاست:
- تمامی عملکردها هم از طریق تاچ خازنی صفحه (`bb_captouch` بر روی پین‌های SDA=8 و SCL=9) و هم از طریق **۱۰ کلید سخت‌افزاری آنالوگ پنل + پدال صنعتی پایی** قابل هدایت است.
- در صورت شکستن شیشه تاچ یا چسبیدن آرد و خمیر روی صفحه، روند تولید دستگاه حتی برای یک لحظه متوقف نمی‌شود.

```text
+-------------------------------------------------------------------------+
|                        HAFFLER BAKERY HMI PANEL                         |
|                                                                         |
|   +-----------------------------------------------------------------+   |
|   |                        480x320 ST7796 LCD                       |   |
|   |   [ حالت خودکار: چانه‌گیری ]             [ شمارش: ۱,۴۵۰ چانه ]   |   |
|   |   پیشرفت سیکل: ▇▇▇▇▇▇▇▇░░ 80%           وزن تنظیمی: ۲۵۰ گرم    |   |
|   +-----------------------------------------------------------------+   |
|                                                                         |
|   [ F1 ]       [ F2 ]       [ F3 ]       [ F4 ]       [ F5 ]            |
|   Auto         Manual       Recipe       Stats        Service           |
|                                                                         |
|   [ M1 ]       [ M2 ]       [ M3 ]       [ M4 ]       [ M5 ]            |
|   Next/Up      Prev/Down    Save/OK      START        STOP/ESTOP        |
+-------------------------------------------------------------------------+
```

## ۲. مشخصات سخت‌افزاری نردبان‌های مقاومتی کلیدها

کلیدها از طریق دو کانال مبدل آنالوگ به دیجیتال ADC1 میکروکنترلر ESP32-S3 خوانده می‌شوند:

| پنل کلید | پایه GPIO | کانال ADC | محدوده ولتاژ | کلیدها و کاربرد اختصاص‌یافته |
|---|---|---|---|---|
| **پنل عملکرد (Function Keys)** | **GPIO 1** | ADC1_CH0 | ۰ الی ۳.۳ ولت | **F1 تا F5:** ناوبری بین صفحات و انتخاب دستور پخت |
| **پنل فرمان (Motion & Modals)** | **GPIO 2** | ADC1_CH1 | ۰ الی ۳.۳ ولت | **M1 تا M5:** تنظیم مقادیر، ذخیره، شروع و توقف سیکل |
| **پدال صنعتی پایی** | **GPIO 7** (I7) | ورودی دیجیتال اپتو | ۲۴V صنعتی | شروع تک‌سیکل چانه‌گیری یا توقف اضطراری (پدال دوبل) |

### جدول تفکیک مقادیر ADC و دیبانس سخت‌گیرانه:

| کلید | بازه قرائت ADC (0..4095) | ولتاژ تفکیک‌شده | نقش در ناوبری | نقش در چرخه ماشین |
|---|---|---|---|---|
| **F1 / M1** | ۴۰۰۰ تا ۴۰۹۵ | ۳.۲ الی ۳.۳ ولت | F1: صفحه اصلی / خودکار | M1: افزایش مقدار (+) / حرکت فوکوس به جلو |
| **F2 / M2** | ۳۳۰۰ تا ۳۶۰۰ | ۲.۶ الی ۲.۸ ولت | F2: صفحه دستی و جاگ | M2: کاهش مقدار (-) / حرکت فوکوس به عقب |
| **F3 / M3** | ۲۷۰۰ تا ۲۹۰۰ | ۲.۱ الی ۲.۳ ولت | F3: تنظیمات وزن و قیف | M3: تایید / ذخیره پارامترها (Save / OK) |
| **F4 / M4** | ۱۹۰۰ تا ۲۱۰۰ | ۱.۵ الی ۱.۷ ولت | F4: آمار و گزارش تولید | **M4: شروع چرخه اتوماتیک چانه‌گیری (START)** |
| **F5 / M5** | ۱۱۰۰ تا ۱۴۰۰ | ۰.۹ الی ۱.۱ ولت | F5: سرویس و قفل روزشمار| **M5: توقف اضطراری آنی سیکل (STOP)** |
| **Idle** | کمتر از ۸۰۰ | کمتر از ۰.۶ ولت | هیچ کلیدی فشرده نیست | وضعیت عادی (شناور) |

## ۳. الگوریتم ناوبری بدون تاچ در صفحات و مودال‌ها

### الف) جابه‌جایی بین تب‌ها و صفحات اصلی
- فشردن مستقیم کلیدهای **F1 تا F5** فوراً صفحه متناظر را لود می‌کند:
  - `F1`: سوئیچ به صفحه اتوماتیک (`AutomaticMode`)
  - `F2`: سوئیچ به صفحه تست دستی و حرکت تک‌تک موتورها (`ManualScreen`)
  - `F3`: ورود به پارامترهای وزن چانه و زمان تغذیه قیف (`SettingsScreen`)
  - `F4`: نمایش آمار شیفت، سرعت چانه‌گیری و شمارنده کل (`StatsScreen`)
  - `F5`: صفحه لایسنس، قفل روزشمار و عیب‌یابی اینورتر (`ServiceScreen`)

### ب) تنظیم مقادیر عددی بدون کیبورد مجازی (Numeric Virtual Keypad Bypass)
1. در صفحات تنظیمات، با فشردن کلیدهای **M1 (بعدی)** و **M2 (قبلی)** کادر فوکوس زرد/آبی رنگ به ترتیب روی فیلدها حرکت می‌کند:
   - فیلد ۱: زمان برش پیستون / وزن چانه (`auto_weight` با گام ۱۰ میلی‌ثانیه یا ۱ گرم).
   - فیلد ۲: زمان جلو آمدن قیف خمیر (`setting_max_funnle` با گام ۵۰ میلی‌ثانیه).
   - فیلد ۳: وقفه ریتم بین دو چانه (`auto_speed` با گام ۱۰۰ میلی‌ثانیه).
2. فشردن کلید **M3 (ویرایش/تایید)** فیلد را وارد حالت ویرایش (Edit Mode) می‌کند.
3. در حالت ویرایش:
   - `M1`: افزایش مقدار (+۱۰ یا +۵۰ با نگه داشتن کلید شتاب می‌گیرد).
   - `M2`: کاهش مقدار (-۱۰ یا -۵۰ با نگه داشتن کلید شتاب می‌گیرد).
   - `M3`: ذخیره قطعی در NVS و خروج از حالت ویرایش.
   - `M5`: انصراف بدون ذخیره.

## ۴. استانداردهای ایمنی کنترل حرکتی بدون تاچ

1. **اولویت مطلق کلید M5 (Hardware Stop Priority):**
   - فارغ از اینکه سیستم در کدام صفحه، منو یا مودال تنظیمات باشد، فشردن کلید **M5** فوراً رله‌های موتور پیستون (Q7)، موتور قیف (Q1) و هر دو جهت اینورتر را در کمتر از ۵ میلی‌ثانیه غیرفعال (`HIGH/OFF`) می‌کند.
2. **شروع دومرحله‌ای جهت پیشگیری از خطای اپراتور:**
   - فشردن کلید **M4 (START)** در صورتی که قیف یا پیستون در مبدا نباشند، ابتدا سیکل هومینگ (`STATE_FUNNEL_HOME`) را فعال کرده و با صدای بیپ ممتد شروع کار را هشدار می‌دهد.
3. **فیدبک صوتی متمایز با بازر (GPIO 45):**
   - کلیدهای F1..F5: تک بوق کوتاه ۲۰ میلی‌ثانیه.
   - کلید M3 (ذخیره): دو بوق کوتاه ۳۰ میلی‌ثانیه.
   - کلید M4 (استارت): بوق کشیده ۱۰۰ میلی‌ثانیه.
   - کلید M5 (استاپ / خطا): ۳ بوق هشداردهنده ۱۰۰ میلی‌ثانیه.
