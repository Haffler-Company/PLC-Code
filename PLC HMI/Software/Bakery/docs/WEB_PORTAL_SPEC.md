# مشخصات پرتال وب و تله‌متری زنده (Industrial Web Portal & Telemetry Specification)
## دستگاه چانه‌گیر و گردکن خمیر نانوایی هافلر (Haffler Bakery HMI)

این مستند تشریح‌کننده ساختار وب‌سرور صنعتی، نقطه دسترسی بی‌سیم (SoftAP)، اندپوینت‌های RESTful API، خروجی گزارش شیفت تولید با فرمت CSV و امکانات ارتقای فریم‌ور از طریق مرورگر است.

---

## ۱. معماری شبکه و وب‌سرور محلی

کنترلر ESP32-S3 دستگاه چانه‌گیر به عنوان یک اکسس‌پوینت صنعتی مستقل عمل می‌کند:
- **نام شبکه وای‌فای (SSID):** `Haffler-Bakery-[4-Digit-ID]` (مثلاً `Haffler-Bakery-1042`)
- **رمز عبور پیش‌فرض:** `haffler-bakery`
- **آدرس آی‌پی پرتال:** `192.168.4.1` (پورت استاندارد HTTP 80)
- **پروتکل ارتباطی:** پرتال محلی بدون نیاز به اینترنت، با پشتیبانی کامل از تبلت، گوشی هوشمند و لپ‌تاپ مدیر نانوایی.
- **ایزولاسیون هسته پردازشی:** تمامی درخواست‌های وب، کدهای HTML/JS و سرویس‌های فایل منحصراً در **Core 0** اجرا می‌شوند تا کوچک‌ترین لگی در رندرینگ ۵۰ فریم LVGL در **Core 1** رخ ندهد.

---

## ۲. داشبورد تله‌متری زنده (Live Production Dashboard)

صفحه اصلی وب‌پورتال شامل پنل‌های نظارت بلادرنگ است:
1. **شمارشگر چانه خمیر (Dough Piece Counter):**
   - تعداد چانه‌های تولید شده در شیفت جاری.
   - تعداد کل چانه‌های بریده‌شده در طول عمر دستگاه.
2. **پارامترهای جاری دستور پخت (Active Recipe Parameters):**
   - وزن تنظیم‌شده چانه (زمان برش پیستون به میلی‌ثانیه / تخمین گرم).
   - سرعت تغذیه قیف (`setting_max_funnle` به میلی‌ثانیه).
   - ریتم و وقفه سیکل چانه‌گیری (`auto_speed`).
3. **وضعیت سخت‌افزار و الکتروموتورها:**
   - فرکانس و جهت اینورتر (راست‌گرد / چپ‌گرد).
   - دمای موتورها و محیط از طریق ترموکوپل‌های صنعتی MAX6675.
   - وضعیت سنسورهای القایی موقعیت قیف (I6) و پیستون (I7).

## ۳. مشخصات اندپوینت‌های REST API

| آدرس اندپوینت | متد HTTP | ساختار داده (Payload) | توضیحات عملکرد |
|---|---|---|---|
| `/api/status` | GET | JSON | دریافت کلیه داده‌های تله‌متری زنده (شمارنده، دماها، خطاها، وضعیت سیکل) |
| `/api/settings` | GET | JSON | دریافت مقادیر پارامترهای پایدار NVS |
| `/api/settings` | POST | JSON | ذخیره پارامترهای جدید وزن چانه، زمان قیف و سرعت |
| `/api/export_csv` | GET | Stream (text/csv) | **دانلود مستقیم فایل گزارش تولید شیفت کاری با فرمت اکسل/CSV** |
| `/api/command` | POST | JSON | ارسال فرمان کنترل مجاز (ریست شمارنده شیفت، کالیبراسیون دما) |
| `/update` | POST | Multipart | بارگذاری فایل `firmware.bin` جهت آپدیت محلی بدون کابل |

## ۴. ساختار فایل اکسل/CSV گزارش تولید شیفت (`/api/export_csv`)

پرتال امکان استخراج فایل گزارش عملکرد روزانه را در اختیار سرپرست کارگاه قرار می‌دهد. ساختار فایل دانلود شده:

```csv
Timestamp,Shift_ID,Dough_Pieces,Weight_Setting_ms,Funnel_Feed_ms,Run_Time_Minutes,Average_Speed_Dough_Per_Min,Alarm_Count
2026-09-07 06:00:00,Shift-Morning,1450,350,1200,240,6.04,0
2026-09-06 14:00:00,Shift-Evening,1820,350,1200,300,6.06,1
```

## ۵. امنیت پرتال و حفاظت در برابر تداخل کاری

1. **جلوگیری از ارسال فرمان‌های متناقض:**
   - هیچ فرمانی از طریق وب‌پورتال نمی‌تواند ایمنی فیزیکی دستگاه را دور بزند (تایم‌اوت ۵۰۰۰ میلی‌ثانیه سنسورها و اینترلاک ۱۰۰ میلی‌ثانیه اینورتر همواره بر روی پردازنده حاکم است).
2. **احراز هویت تنظیمات:**
   - ذخیره تغییرات وزن یا پارامترها از طریق وب نیازمند ارسال توکن یا رمز عبور مدیر است.
3. **تولید محتوای سبک بدون کتابخانه‌های سنگین خارجی:**
   - فرانت‌اند وب‌پورتال از فریم‌ورک‌های سنگین (React/Vue) استفاده نمی‌کند؛ بلکه تماماً با HTML5 و CSS بهینه‌شده به صورت فایل فشرده Gzip از حافظه فلش سرو می‌شود تا رم میکروکنترلر اشغال نگردد.
