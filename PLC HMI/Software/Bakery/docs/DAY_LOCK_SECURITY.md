# مشخصات فنی سیستم قفل روزشمار و مدیریت اقساط (Day-Lock & Leasing Security)
## Haffler Industrial Bakery Dough Divider — Master Offline Challenge-Response Architecture

این مستند تشریح‌کننده الگوریتم امنیتی، معماری چالش/پاسخ آفلاین، دوره‌های تنفس اضطراری، حفاظت طول عمر فلش، و گارد ضد دستکاری ساعت سخت‌افزاری در دستگاه چانه‌گیر نانوایی شرکت هافلر است.

## ۱. معماری ماشین وضعیت ۶‌گانه (PackML Aligned FSM)

چرخه لیزینگ و روزشمار دستگاه توسط یک ماشین وضعیت ۶‌حالته قطعی کنترل می‌شود:

```text
                  ┌──────────────────────────────────────┐
                  │        STAGE 0: FACTORY FREE         │
                  │ (کارکرد آزاد دائمی بدون روزشمار)     │
                  └──────────────────────────────────────┘
                                     │ فعال‌سازی توسط کارخانه یا ادمین
                                     ▼
                  ┌──────────────────────────────────────┐
                  │        STAGE 1: ACTIVE LEASE         │
                  │ (روزشمار فعال مراحل T1 تا T5)        │
                  └──────────────────────────────────────┘
                                     │ روزهای باقیمانده == 0
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                          فاز اتمام مهلت و انقضا                         │
│                                                                        │
│   ┌──────────────────────────┐          ┌──────────────────────────┐   │
│   │ STAGE 2: 10-DAY GRACE    │ ◄─[112233]─│ STAGE 3: SOFT LOCKOUT    │   │
│   │ (مهلت اضطراری ۱۰ روزه)   │          │ (اتمام ایمن چرخه برش)    │   │
│   └──────────────────────────┘          │ (جلوگیری از شروع چرخه نو)│   │
│                │ اتمام ۱۰ روز            └──────────────────────────┘   │
│                └───────────────────────┐               │ بوت نو یا درنگ│
│                                        ▼               ▼               │
│                                 ┌──────────────────────────┐           │
│                                 │ STAGE 4: HARD LOCKOUT    │           │
│                                 │ (قطع کلیه خروجی‌ها)      │           │
│                                 │ (صفحه قفل سفید اپل بالا) │           │
│                                 └──────────────────────────┘           │
│                                                │ کشف دستکاری ساعت/باتری │
│                                                ▼                       │
│                                 ┌──────────────────────────┐           │
│                                 │ STAGE 5: TAMPER LOCKDOWN │           │
│                                 │ (قفل بحرانی ضد دستکاری)  │           │
│                                 └──────────────────────────┘           │
└────────────────────────────────────────────────────────────────────────┘
```

### جدول رفتار وضعیتی ماشین:

| کد وضعیت | عنوان وضعیت | رفتار محرک‌های فیزیکی چانه‌گیر | بازخورد رابط کاربری (HMI) | بیزر هشدار |
| :---: | :--- | :--- | :--- | :--- |
| **0** | **FACTORY FREE** | کارکرد ۱۰۰٪ آزاد اتوماتیک و دستی | هیچ نشانگر قفلی وجود ندارد | خاموش |
| **1** | **ACTIVE LEASE** | کارکرد نرمال؛ کسر ۱ روز به ازای هر ۲۴ ساعت | نمایش تعداد روز در هدر منو | دو بیپ کوتاه در بوت هنگام روز $\le 3$ |
| **2** | **10-DAY GRACE** | کارکرد نرمال به مدت دقیق ۱۰ روز تقویمی اضطراری | نوار هشدار مهلت اضطراری | صدای آلارم ۳ ثانیه‌ای در هر بوت |
| **3** | **SOFT LOCKOUT** | **اینترلاک اتمام ایمن:** اگر خمیر در حال برش باشد، چرخه تا بازگشت قیف و پیستون کامل می‌شود اما شروع چرخه جدید قفل است | نمایش نوار هشدار انقضا | بیپ‌های متناوب هشدار |
| **4** | **HARD LOCKOUT** | **توقف کامل:** قطع تمامی رله‌های موتور، اینورتر و بازر | مودال تمام‌صفحه سفید برفی Apple HIG با کیپد و کد چالش | تک‌بوق ممتد ۵ ثانیه‌ای در بوت |
| **5** | **TAMPER** | توقف کامل و قفل سخت‌افزاری ضد دستکاری | صفحه قفل قرمز خطای دستکاری ساعت | آلارم منقطع ۲۵۰ms |

## ۲. موتور اعتبارسنجی رمز ۴ لایه‌ای (4-Tier Offline Authentication)

1. **لایه ۱ (Factory Master Clear):**
   - رمزها: `"12773"`، `"123456"`، `"12733"`.
   - نتیجه: پاکسازی کامل متغیرها و بازگرداندن سیستم به حالت STAGE 0 (آزاد کارخانه).
2. **لایه ۲ (Offline Challenge-Response):**
   - دستگاه یک کد چالش تصادفی ۵ رقمی تولید می‌کند (مثلاً `58219`).
   - فرمول کلیدساز کارخانه:
     $$\text{Base} = \text{Challenge} \times 2$$
     $$\text{Checksum} = \text{DigitSum}(\text{Base}) \pmod{10}$$
     $$\text{Response} = \text{Base} \,\|\, \text{Checksum}$$
     *(مثال: چالش `58219` $\to$ Base: `116438` $\to$ رقم کنترلی: `3` $\to$ پاسخ: `1164383`)*
   - نتیجه: تمدید ۳۰ روزه اعتبار دستگاه و بازگشایی قفل.
3. **لایه ۳ (5-Stage Chain Multiplier):**
   - کدهای چندگانه برای اقساط ۵ مرحله‌ای ($T_1 \dots T_5$) بر مبنای رمز ادمین دستگاه (`1234` یا `654321`):
     $$\text{Digit}_i' = (\text{AdminPIN}_i \times (\text{Stage} + 1)) \pmod{10}$$
     $$\text{Code} = \text{Digits}' \,\|\, (\sum \text{Digit}_i' \pmod{10})$$
   - نتیجه: پیشروی به مرحله بعدی و اعمال تعداد روزهای تنظیم‌شده برای آن مرحله.
4. **لایه ۴ (Emergency Grace Code):**
   - رمز نجات اضطراری: `"112233"`.
   - نتیجه: فعال‌سازی یکباره ۱۰ روز مهلت اضطراری جهت جلوگیری از فساد خمیر؛ با سوزاندن دائمی بیت `grace10_used = true` در NVS.

## ۳. حفاظت‌های ضد دستکاری و طول عمر حافظه فلش (Siemens / MISRA Standards)

1. **گارد ساعت یکنواخت صعودی (Monotonic Clock Guard):**
   - خواندن زمان تقویمی از چیپ ساعت صنعتی DS3231.
   - ثبت آخرین زمان معتبر در فیلد `last_known_epoch`.
   - در صورتی که اپراتور ساعت را عقب بکشد ($\text{RTC\_epoch} + 300 < \text{last\_known\_epoch}$)، دستگاه بلادرنگ وارد **STAGE 5: TAMPER LOCKDOWN** می‌شود.
2. **بررسی جدا شدن باتری ساعت (OSF Flag):**
   - خواندن پرچم توقف نوسان‌ساز (Oscillator Stop Flag). در صورت صفر شدن تاریخ به سال ۲۰۰۰، سیستم فریب نخورده و به ثانیه‌شمار مونوک داخل میکرو سوئیچ می‌کند.
3. **حافظه NVS آینه‌ای با CRC32 (Dual-Mirrored Slots):**
   - ذخیره‌سازی داده‌های رکورد قفل در دو اسلات مجزای `meta_a` و `meta_b` به همراه چک‌سام CRC32 سخت‌افزاری ESP32 (`esp_rom_crc32_le`).
   - در صورت قطع ناگهانی برق در میلی‌ثانیه نوشتن یک اسلات، اسلات دیگر سالم مانده و در بوت بعدی خودبه‌خود بازیابی و ترمیم می‌شود.
4. **سیاست فرسایش صفر درصد فلش (Flash Endurance):**
   - ثانیه‌ها فقط در RAM انباشته می‌شوند.
   - نوشتن در NVS صرفاً **هر ۳۶۰۰ ثانیه (۱ ساعت یک‌بار)**، یا هنگام کسر یک روز کامل، یا هنگام اعمال رمز موفق انجام می‌شود که عمر فلش را به بیش از **۱۵ سال** می‌رساند.
5. **محافظت تصاعدی ضد بروت‌فورس (Anti-Brute Force):**
   - ۳ بار اشتباه $\to$ فریز ۳۰ ثانیه‌ای کیپد به همراه تایمر شمارش معکوس زنده.
   - ۵ بار اشتباه $\to$ فریز ۵ دقیقه‌ای.
   - ۱۰ بار اشتباه $\to$ ورود به قفل امنیتی دستکاری (TAMPER).
6. **ناوبری فیزیکی بدون نیاز به تاچ (Touchless Fallback):**
   - در صورت خرابی یا شکستن شیشه تاچ در محیط کارگاه، کلیدهای سخت‌افزاری جلوی پنل (کلید MODE برای جابجایی بین ارقام، START برای انتخاب، و STOP برای حذف DEL) امکان بازگشایی کامل قفل را فراهم می‌کنند.
