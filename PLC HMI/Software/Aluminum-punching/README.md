# Haffler Aluminum Punching Machine (دستگاه پانچ آلومینیوم هافلر)
## مدل: HAFFLER AP-500 | برد صنعتی ETV3A (ESP32-S3 N16R8)

پروژه سیستم کنترل صنعتی و HMI دستگاه پانچ هیدرولیک/پنوماتیک آلومینیوم با رعایت بالاترین استانداردهای ایمنی پرس (EN 693 / EN 574)، حفاظت دو دستی Anti-Tie Down، پرده نوری، شمارنده طول عمر قالب و مانیتورینگ بلادرنگ فشار.
