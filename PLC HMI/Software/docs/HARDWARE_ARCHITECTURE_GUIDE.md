# راهنمای جامع بستر سخت‌افزاری مشترک ماشین‌آلات (Hardware Architecture Guide)
## مستند فنی چیپست، نمایشگر، حسگرها، رله‌ها و ملاحظات الکترونیک صنعتی پروژه‌های HMI هافلر

> **هدف:** ارائه مشخصات دقیق سخت‌افزاری و الگوهای درایور برای ایجنت‌های هوش مصنوعی تا در زمان توسعه نرم‌افزار، کوچک‌ترین فرضیه اشتباه یا تداخلی با معماری فیزیکی بردهای الکترونیکی هافلر نداشته باشند.

---

## ۱. مشخصات واحد پردازش مرکزی (MCU Core Architecture)

تمامی پروژه‌های صنعتی جدید هافلر بر بستر پردازنده **ESP32-S3-WROOM-1 (N16R8)** طراحی و پیاده‌سازی شده‌اند.

```
+-------------------------------------------------------------------------------+
|                       مشخصات چیپ پردازشی ESP32-S3-WROOM-1                     |
+----------------------+--------------------------------------------------------+
| مشخصه فنی            | جزئیات سخت‌افزاری                                      |
+----------------------+--------------------------------------------------------+
| هسته‌های پردازنده     | ۲ هسته ۳۲ بیتی Xtensa® LX7 با کلاک ۲۴۰ مگاهرتز          |
| حافظه فلش (Flash)   | ۱۶ مگابایت Octal SPI Flash با پشتیبانی از دو پارتیشن OTA |
| حافظه رم جانبی(PSRAM)| ۸ مگابایت Octal SPI PSRAM پرسرعت                      |
| حافظه SRAM داخلی     | ۵۱۲ کیلوبایت SRAM (باید ۴۵٪ آزاد بماند برای بافر DMA)  |
| ارتباطات بی‌سیم       | وای‌فای ۲.۴ گیگاهرتز (802.11 b/g/n) + بلوتوث کم‌مصرف BLE  |
+----------------------+--------------------------------------------------------+
```

### ۱.۱. تخصیص وظایف میان هسته‌ها (FreeRTOS Core Affinity)
* **هسته صفر (Core 0 - Interface & Connectivity):**
  - تسک گرافیک و رندر کتابخانه LVGL (معمولاً در دوره تناوب ۲۰ تا ۳۰ میلی‌ثانیه).
  - اسکن مداوم پنل لمسی خازنی GT911.
  - وب‌سرور داخلی (ESPAsyncWebServer / WebApp)، ارتباط وب‌سوکت و پورتال اختصاصی.
  - مدیریت سرویس به‌روزرسانی آنلاین فریمور (OTA Server & Client).
* **هسته یک (Core 1 - Real-time Industrial PLC):**
  - حلقه کنترل قطعی ماشین (سیکل اسکن ثابت ۵۰ تا ۷۰ میلی‌ثانیه).
  - خواندن پالایش‌شده ورودی‌ها و دیبانس سنسورها.
  - اجرای ماشین وضعیت استاندارد فرآیند (FSM).
  - رگولاتور کنترل دمای المنت‌ها (PID Thermal Loop) با ترموکوپل MAX6675.
  - ناظر استاپ اضطراری و مدیریت سلامت خروجی‌های رله.

## ۲. زیرسیستم نمایشگر و پنل لمسی (Display & Touch Subsystem)

### ۲.۱. پنل تصویر (TFT LCD)
* **ابعاد و فناوری:** نمایشگر ۳.۵ یا ۴.۰ اینچ IPS رنگی با زاویه دید عریض (۱۷۸ درجه).
* **رزولوشن فیزیکی:** **۴۸۰ در ۳۲۰ پیکسل** افقی (Landscape).
* **کنترلر درایور تصویر:** تراشه‌های **ILI9488** یا **ST7796S**.
* **پروتکل ارتباطی:** سخت‌افزار Hardware SPI (کانال SPI2 / FSPI) با فرکانس کاری تا **۸۰ مگاهرتز**.
* **عمق رنگ:** ۱۶ بیتی RGB565LE (Little Endian).
* **پیکربندی بافر LVGL:**
  - یک یا دو بافر خطی به اندازه ۴۰ تا ۶۰ خط در حافظه پرسرعت داخلی یا بافر تمام‌صفحه در حافظه PSRAM جهت دستیابی به فریم‌ریت روان ۵۰ الی ۶۰ هرتز بدون پرش (Tearing).

### ۲.۲. پنل لمسی خازنی (Capacitive Touch)
* **کنترلر:** تراشه اختصاصی **Goodix GT911** (یا در برخی نسخه‌ها CST816 / FT6x36).
* **پروتکل ارتباطی:** I2C سخت‌افزاری فرکانس ۴۰۰ کیلوهرتز (I2C0).
* **موقعیت سنسور:** شیشه حرارت‌دیده صنعتی مقاوم در برابر خط‌وخش، نفوذ روغن و پاشش قطرات آب.
* **فیلتر نرم‌افزاری:** مجهز به الگوریتم حذف نویز لبه‌ای و تصحیح مختصات برای پیشگیری از لمس‌های کاذب (Ghost Touch) در اثر شوک‌های الکترومغناطیسی کارگاه.

## ۳. حسگرهای صنعتی و تجهیزات سنجش (Sensors & Peripherals)

```
        +---------------------------------------------+
        |                 ESP32-S3                    |
        |                                             |
        |  [I2C0] ----> GT911 Touch Controller        |
        |         ----> DS3231 High-Precision RTC     |
        |                                             |
        |  [SPI2] ----> ILI9488 / ST7796 LCD Display  |
        |                                             |
        |  [SPI/GPIO]-> Dual MAX6675 Thermocouples    |
        |                                             |
        |  [GPIO] ----> Optocoupled Inputs (24V/5V)   |
        |         ----> Active-LOW Relay Drivers      |
        |         ----> Piezo Buzzer (PWM)            |
        +---------------------------------------------+
```

### ۳.۱. ساعت صنعتی با تصحیح دمایی (Dallas DS3231 RTC)
* ارتباط روی باس مشترک I2C0 با آدرس پیش‌فرض `0x68`.
* مجهز به کریستال ساعت داخلی تصحیح‌شده با دما (TCXO) با خطای کمتر از ۱ دقیقه در سال.
* مجهز به باتری پشتیبان سکه‌ای (CR1220 / CR2032) برای حفظ ساعت هنگام قطعی کامل برق دستگاه.
* نرم‌افزار مجهز به مبدل دوطرفه تقویم میلادی به شمسی/جلالی جهت ثبت شیفت‌ها و لاگ‌های فارسی.

### ۳.۲. ماژول‌های سنجش دمای فک جوش (Dual MAX6675)
* پروتکل رابط سریال سه‌سیمه با جبران‌ساز پیوند سرد (Cold-Junction Compensation).
* اتصال مستقیم به ترموکوپل‌های صنعتی تیپ K با غلاف فلزی.
* محدوده سنجش: ۰ الی ۱۰۲۴ درجه سانتی‌گراد با تفکیک‌پذیری ۰.۲۵ درجه.
* مجهز به مدار نرم‌افزاری تشخیص قطعی سیم سنسور (Open Thermocouple Detection).

## ۴. رابط‌های ورودی و خروجی قدرت (I/O & Relay Architecture)

### ۴.۱. خروجی‌های رله و بوبین‌ها (Relay Outputs)
* تمامی رله‌ها در سطح سخت‌افزار به صورت **تحریک منفی (Active-LOW)** راه‌اندازی می‌شوند:
  - نوشتن `LOW` (`0` منطقی): مدار فعال و بوبین برق‌دار می‌شود.
  - نوشتن `HIGH` (`1` منطقی): مدار قطع و بوبین بی‌برق می‌شود.
* **قانون راه‌اندازی امن (Boot Safe State):**  
  در بدنه تابع `setup()` یا مقداردهی اولیه سیستم، پیش از تنظیم پین‌ها به عنوان `OUTPUT`، باید سطح اولیه آن‌ها حتماً روی `HIGH` نگه داشته شود:
  ```c
  gpio_set_level(RELAY_PIN, 1); // تضمین وضعیت خاموش قبل از فعال‌سازی خروجی
  gpio_set_direction(RELAY_PIN, GPIO_MODE_OUTPUT);
  ```

### ۴.۲. ورودی‌های دیجیتال و سوئیچ‌ها (Digital Inputs)
* تمام ورودی‌ها از مدارات ایزولاسیون نوری (Optocoupler) عبور کرده و روی سطح برد مجهز به مقاومت‌های پول‌آپ سخت‌افزاری هستند.
* ورودی‌های نرمال به صورت Active-LOW طراحی شده‌اند (اتصال به زمین = فعال شدن سوئیچ).
* پین‌های ورودی شامل:
  1. پدال پایی اپراتور (Foot Pedal Switch).
  2. شستی استارت چرخه (Cycle Start).
  3. کلید قارچی استاپ اضطراری (Emergency Stop Mushroom Button).
  4. میکروسوئیچ‌های موقعیت جک‌ها و حسگرهای القایی (Inductive Proximity Sensors).

## ۵. ملاحظات حفاظت الکترومغناطیسی در محیط کارگاهی (Industrial EMI / EMC Rules)

محیط کاری ماشین‌آلات تولیدی هافلر شامل دستگاه‌های جوشکاری با قوس الکتریکی، موتورهای سه‌فاز اینورتری (VFD) و شیرهای پنوماتیک بزرگ است که نویزهای فرکانس‌بالا و پیک‌های ولتاژی القایی تولید می‌کنند.

1. **مدارات اسنابر (RC Snubber / Flyback Diodes):**  
   تمامی بوبین‌های ۲۴ ولت و کنتاکتورهای ۲۲۰ ولت باید مجهز به دیود هرزگرد یا اسنابر موازی باشند تا ولتاژ بازگشتی سلفی، باعث ریست تصادفی پردازنده نشود.
2. **جداسازی زمین قدرت از زمین سیگنال:**  
   تغذیه بخش منطقی ۵V/3.3V نمایشگر و پردازنده به کمک منبع تغذیه سوئیچینگ ایزوله با فیلتر ورودی EMI از تغذیه بخش قدرت رله‌ها تفکیک شده است.
3. **طراحی واچ‌داگ دوگانه (Dual Watchdog):**  
   - واچ‌داگ سخت‌افزاری داخلی ESP32 (Task WDT) روی هسته‌های ۰ و ۱ فعال است (حداکثر زمان مجاز ۵۰۰۰ میلی‌ثانیه).
   - مدار رله ریست سراسری (`RESET_RELAY_GPIO`) جهت ریست سخت‌افزاری سیستم در شرایط بحرانی.
