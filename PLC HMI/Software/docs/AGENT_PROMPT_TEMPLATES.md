# Haffler PLC Fleet — Agent Prompt Templates
## پرامپت‌های بهینه آماده برای وظایف رایج

> **هدف:** کارفرما این پرامپت‌های آماده را کپی کرده و مستقیم به ایجنت بدهد.
> هر پرامپت بهینه‌شده است تا بدون رفت‌وبرگشت اضافه، خروجی صحیح تولید شود.

## 🖥️ HMI / UI Tasks

### PROMPT-UI-01: اضافه کردن صفحه جدید
```
پروژه: [نام ماشین]
وظیفه: صفحه جدید با نام [نام صفحه] اضافه کن.
ورودی‌های نمایشی: [لیست متغیرها که باید نشان داده شوند]
دکمه‌ها: [لیست دکمه‌ها و عملکرد هر کدام]
ناوبری: از صفحه [X] بیاید، به صفحه [Y] برود.
استاندارد: Apple HIG dark slate #334155، بدون سایه، خط دور ۱px، ارگونومی ۴۴px.
قوانین: رشته‌ها در ui_lang.h، dirty-driven update، بدون malloc.
```

### PROMPT-UI-02: اصلاح تراز و افتادگی اعداد
```
پروژه: [نام ماشین]
مشکل: اعداد در کادر [نام کادر] در صفحه [نام صفحه] کج/افتاده هستند.
راه‌حل موردانتظار: کانتینر با pad_all=0 + lv_obj_center(lbl).
اثر جانبی مجاز: صفر — فقط این کادر اصلاح شود.
```

### PROMPT-UI-03: اضافه کردن توکن زبانی جدید
```
پروژه: [نام ماشین]
توکن جدید: STR_[نام] 
ترجمه فارسی: [متن]
ترجمه انگلیسی: [text]
ترجمه ترکی: [metin] (از حروف ASCII استفاده کن — ü→u, ç→c, ı→i, ş→s, ğ→g, ö→o)
محل استفاده: [فایل و تابع]
```

### PROMPT-UI-04: سوئیچ زبان — رفع نشت (Language Leak Fix)
```
پروژه: [نام ماشین]
مشکل: هنگام تغییر زبان به انگلیسی، [برچسب‌های X] همچنان فارسی می‌مانند.
بررسی کن: آیا این برچسب‌ها در s_stepper_cards یا s_label_registry ثبت شده‌اند؟
اصلاح: همه برچسب‌های ثبت‌نشده را به رجیستری اضافه کن و ui_screens_refresh_language() را بروز کن.
```

## ⚡ ابزار خودکارسازی و باگ‌گیری پرامپت (Prompt Architect Pro)

اگر وقت نوشتن دستی ندارید، دستور عامیانه خود را مستقیم به ابزار ۲۱ کلیده بدهید تا در ۱.۲ ثانیه کپسول مهندسی ضدباگ بسازد:

```powershell
# ۱. تولید کپسول مهندسی جراحی برای ایجنت‌های کدنویس (Cursor, Windsurf, Claude Code):
python tools/haffler_prompt_pro.py "دستور یا خواسته عامیانه شما"

# ۲. عیب‌یابی و گزارش باگ‌های پرامپت شما:
python tools/haffler_prompt_pro.py "پرامپت شما" --mode audit

# ۳. تولید پرامپت جامع برای چت‌بات‌ها (ChatGPT, Gemini, Claude):
python tools/haffler_prompt_pro.py "موضوع مورد نظر" --mode general --lang fa
```

## 💡 HOW TO USE
1. پرامپت مناسب را کپی کن یا از `haffler_prompt_pro.py` پرامپت آماده بگیر.
2. براکت‌ها `[...]` را با اطلاعات واقعی پر کن.
3. مستقیم به ایجنت بده.
4. نیازی به توضیح اضافه نیست — ایجنت بقیه را از مستندات می‌خواند.
