# Agent Orchestrator — ارکستراتور و مدیر تسک‌های چند ایجنتی

این مهارت مسئول معماری وظایف، تجزیه درخواست‌های پیچیده به زیرتسک‌های مستقل (Orthogonal Tasks) و مدیریت موازی‌سازی بدون تداخل دامنه فایل‌ها است.

## اصول کلیدی اجرا
1. **جداسازی کامل دامنه‌ها (Non-overlapping Scope):** هیچ دو ایجنتی نباید روی فایل یکسان یا فایل‌های وابسته همزمان بنویسند.
2. **کپسول‌سازی وظایف:** هر زیر-ایجنت دقیقاً فایل‌های هدف، ورودی، خروجی و روش اعتبارسنجی را دریافت می‌کند؛ ارسال کل تاریخچه چت ممنوع است.
3. **نقش‌های فقط‌خواندنی (Read-Only Specialists):** ایجنت‌های پژوهشگر و داور (Judge/Researcher) دسترسی نوشتن ندارند و فقط گزارش فنی می‌دهند.
4. **تلفیق نهایی توسط مدیر (Single Source of Truth):** تصمیم‌گیری نهایی و ادغام نتایج تنها بر عهده مدیر ارشد است.

## ماتریس تقسیم کار نمونه
- **تسک UI:** ویرایش screens.c و styles.c توسط ایجنت طراح رابط کاربری.
- **تسک Logic/ISR:** ویرایش GasFilling_HMI.ino و ctions.c توسط ایجنت مهندس ارشد فریم‌ور.
- **تسک بازبینی:** بررسی عدم وجود خطای کامپایل، تست حافظه و رگرسیون تاچ توسط ایجنت داور.
