# Strict HMI Firmware Judge — داوری و ممیزی سخت‌گیرانه فریم‌ور

این مهارت به عنوان ناظر و داور مستقل کیفیت عمل کرده و هر تغییر را با معیارهای قطعی زیمنس و ایمنی فرآیند می‌سنجد.

## چک‌لیست ممیزی
1. **آیا قطبیت خروجی (N.O / N.C) تغییر نکرده است؟**
2. **آیا متغیرهای مشترک بین ISR و حلقه اصلی olatile یا tomic هستند؟**
3. **آیا بافر استرینگ‌ها ایمن بوده و خطر Overflow وجود ندارد؟**
4. **آیا در تابع onTimer یا وقفه‌ها تابع غیرایمن صدا زده نشده است؟**
5. **آیا ابعاد و لمس دکمه‌ها حداقل ۴۰×۴۰ پیکسل است؟**
