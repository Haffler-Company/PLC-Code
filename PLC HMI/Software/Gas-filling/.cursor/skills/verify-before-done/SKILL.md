# Verify Before Done — اعتبارسنجی نهایی شواهد

هیچ تسکی بدون ارائه شواهد قطعی (Evidence-based verification) نباید خاتمه‌یافته اعلام شود.

## سطوح اعتبارسنجی
1. **بررسی کد (Source Inspection):** اطمینان از سینتکس صحیح و ساختار استاندارد.
2. **بیلد موفق (Build Evidence):** ثبت خروجی uild.ps1 با وضعیت BUILD OK و اندازه دقیق حافظه فلش و رم.
3. **فلش سخت‌افزاری (Hardware Flash Evidence):** ثبت خروجی اتصال و رایت موفق باینری روی پورت COM هدف.
4. **گزارش شفاف:** ذکر فایل‌های تغییریافته، نسخه فریم‌ور، پورت هدف و موارد تست‌شده.
