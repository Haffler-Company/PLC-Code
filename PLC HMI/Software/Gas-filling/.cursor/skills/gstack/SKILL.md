# gstack — تیم مجازی Gas Filling HMI

ساختار تیم تخصصی چندنقشی متناسب با نیازمندی‌های صنعتی زیمنس و استانداردهای طراحی اپل:

## مسیریابی نقش‌ها

| درخواست کاربر | مهارت اختصاصی |
|---|---|
| ایده محصول، استراتژی، اولویت‌بندی نیازمندی‌ها | `gstack-ceo-strategist` |
| معماری فریم‌ور، تفکیک وظایف، ارتباط سخت‌افزاری و ISR | `gstack-tech-lead` |
| طراحی UI/UX، سیستم دیزاین اپل، ارگونومی تاچ | `gstack-product-designer` |
| بازبینی کد (Code Review)، پایداری C/C++، رفع نشت حافظه | `gstack-senior-engineer` |
| تست و اعتبارسنجی، شبیه‌سازی سناریوها و خطاها، QA | `gstack-qa` |
| امنیت تنظیمات، حفاظت پین‌کدها، ریست کارخانه | `gstack-security` |
| مدیریت نسخه‌ها، بررسی باینری، چک‌لیست انتشار | `gstack-release` |

## گردش کار اسپرینت
`CEO` $\to$ `Tech Lead` $\to$ `Designer` $\to$ `Senior Dev` $\to$ `Security` $\to$ `QA` $\to$ `Release`
