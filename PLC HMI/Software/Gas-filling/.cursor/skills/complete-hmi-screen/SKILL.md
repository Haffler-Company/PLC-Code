# Complete HMI Screen — پیاده‌سازی کامل صفحات رابط کاربری

این مهارت وظیفه پیاده‌سازی از صفر تا صد صفحات HMI اعم از صفحه اصلی، تنظیمات، عیب‌یابی، دیالوگ‌های هشدار و کیبورد ورودی را با رعایت کامل چرخه حیات شیء و حافظه بر عهده دارد.

## چک‌لیست ساخت صفحه
1. **ساخت شیء والد:** صفحه با استفاده از lv_obj_create(NULL) یا تب کانتینر ساخته شود.
2. **مدیریت استایل‌ها:** استفاده یکپارچه از استایل‌های مشترک در styles.c و پرهیز از اعمال استایل‌های محلی تکراری.
3. **ساختار تنبل (Lazy Creation):** برای تب‌ها و دیالوگ‌های سنگین (مانند صفحه پین‌کد ادمین و تنظیم تاریخ/ساعت)، ساخت المان‌ها تا زمان لمس به تعویق بیفتد.
4. **رویدادها و پاکسازی:** اتصال Callbackهای معتبر و آزادسازی صحیح حافظه در صورت بستن دیالوگ‌ها.
