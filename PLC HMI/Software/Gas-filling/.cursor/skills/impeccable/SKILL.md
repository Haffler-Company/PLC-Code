# Impeccable — استاندارد بی‌نقص رابط کاربری فارسی

این مهارت وظیفه اعتبارسنجی کیفیت نهایی نمایش متون فارسی، راست‌به‌چپ (RTL)، شکل‌گیری حروف (Bidi/Shaping) و ارگونومی صنعتی را بر عهده دارد.

## خطوط قرمز نمایش فارسی
1. **عدم اختلاط حروف لاتین و فارسی:** از چسباندن نامناسب کلمات انگلیسی در میانه عبارات فارسی پرهیز شود.
2. **فونت رسمی پروژه:** استفاده انحصاری از فونت‌های بهینه‌شده پروژه (Vazirmatn و Arial عددی).
3. **تراز متن و جهت‌گیری:** جهت نمایش مقادیر متنی بر اساس محتوا (راست‌چین برای توضیحات و چپ‌چین برای ارقام و فرمول‌ها).
4. **تست روی رزولوشن واقعی:** تست برش نخوردن انتهای کلمات در لیبل‌ها با اندازه‌گیری دقیق عرض متن (lv_text_get_size).
