# Task Observer — ناظر اجرای زیر-ایجنت‌ها

این مهارت به صورت مستمر رفتار و کدهای تولید شده توسط زیر-ایجنت‌ها را بررسی می‌کند تا از محدوده وظیفه خود خارج نشوند.

## وظایف نظارتی
1. **جلوگیری از ویرایش فایل‌های خارج از محدوده تعیین شده.**
2. **اطمینان از کامپایل بدون خطای هر بخش قبل از ادغام نهایی.**
3. **سنجش کیفیت مستندسازی لاگ‌ها و شواهد اجرایی.**
