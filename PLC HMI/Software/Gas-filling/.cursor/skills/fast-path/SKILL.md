# Fast Path — مسیر سریع تغییرات جزئی

این مهارت برای اعمال اصلاحات سریع در متون، رنگ‌ها، پدینگ‌ها یا پارامترهای ثابت بدون درگیر کردن جریان‌های سنگین طراحی شده است.

## مراحل اجرای سریع
1. **خواندن دقیق محدوده مورد نظر:** فقط خطوط هدف را بخوانید (iew_file با StartLine/EndLine).
2. **ویرایش متمرکز:** استفاده از 
eplace_file_content فقط روی بلوک تغییر یافته.
3. **کامپایل سریع:** استفاده از scripts/program.ps1 -Force برای کامپایل مجدد فایل اسکچ با استفاده از کش کتابخانه‌ها.
4. **تست و تایید:** مشاهده نتیجه سریع بدون دستکاری زیرساخت‌های پایه.
