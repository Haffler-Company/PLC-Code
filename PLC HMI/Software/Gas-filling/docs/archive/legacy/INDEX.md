# Documentation Index

Read these documents in order when opening the project:

1. `AGENT_START_HERE.md`
2. `GAS_FILLING_SCENARIO.md`
3. `GAS_FILLING_TECHNICAL_KNOWLEDGE.md`
4. `AGENT_HMI.md`
5. `CHANGE_READINESS_CHECKLIST.md`

## Files

| File | Purpose |
| --- | --- |
| `AGENT_START_HERE.md` | First briefing for future agents. |
| `GAS_FILLING_SCENARIO.md` | Machine behavior, screens, controls, outputs, and current code mapping. |

| `REFERENCE_PROJECTS_INDEX.md` | How imported reference projects should be used. |
| `TRANSFERRED_RULES.md` | Practical rules transferred from the reference projects. |
| `BUILD_AND_VERSION.md` | Fast build/upload, version bump, rollback, `-Knowledge` gate. |
| `WORK_ITEMS.md` | Future improvements and technical debt. |

The `docs/reference-projects` folder contains imported source material. Some files there may remain in their original language because they are historical references, not the canonical agent briefing for this project.
