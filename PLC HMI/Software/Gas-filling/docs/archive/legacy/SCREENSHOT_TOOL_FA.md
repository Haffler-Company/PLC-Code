# ابزار اسکرین‌شات صفحه HMI — پروتکل آسنکرون بدون وقفه (Zero-Lag Snapshot)

ابزار فوق سریع دریافت عکس واقعی فریم‌بافر صفحه نمایشگر با نرخ تبادل **۹۲۱,۶۰۰ باود** و کپی مستقیم در حافظه (بدون قفل کردن یا هنگ کردن صفحه HMI و PLC).

## مزایا و معماری جدید
1. **Zero UI Freeze:** فرآیند عکس‌برداری در کمتر از ۱۵ میلی‌ثانیه مستقیماً در حافظه رم/PSRAM انجام شده و نخ گرافیکی (UI) بلافاصله آزاد می‌شود.
2. **ارسال در تسک پس‌زمینه (Background Worker):** انتقال داده‌های سریال در هسته ۰ بدون تداخل با کنترل ماشین و ورودی‌های تاچ انجام می‌شود.
3. **سرعت ۳ ثانیه‌ای:** با نرخ ۹۲۱,۶۰۰ باود کل فریم در حدود ۳ الی ۴ ثانیه دانلود و ذخیره می‌شود.

## پیش‌نیازها (سمت PC)

```powershell
pip install pyserial pillow
```

## نحوه استفاده

```powershell
# تشخیص خودکار پورت CP210x و گرفتن عکس فوری
python tools/hmi_screenshot.py

# با مشخص کردن پورت دلخواه
python tools/hmi_screenshot.py --port COM8 --baud 921600 --out screenshot.png
```
