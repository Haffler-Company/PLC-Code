# مشخصات فنی سامانه راهنمای تعاملی و دیاگرام‌های درون‌برنامه‌ای (In-HMI Help & Diagnostic Modal)
## Operator Guidance, Wiring Schematics & Visual Diagnostic Engine — Gas Filling HMI

این مستند تشریح‌کننده ساختار فنی، محتوا و نحوه پیاده‌سازی سامانه راهنمای ۶ کارته داخلی دستگاه گاز پرکن هافلر است که مستقیماً روی صفحه نمایشگر HMI ظاهر شده و اپراتور را در محیط کارگاه از دفترچه راهنمای کاغذی بی‌نیاز می‌سازد.

---

## ۱. فلسفه طراحی راهنمای گرافیکی درون‌برنامه‌ای

در محیط‌های صنعتی، دفترچه‌های کاغذی گم شده یا بر اثر چسب و رطوبت تخریب می‌شوند. راهنمای دیجیتال روی صفحه نمایشگر دارای مزایای زیر است:
- دسترسی فوری با یک لمس روی آیکون راهنما یا کلید کمکی.
- چندزبانه بودن (پشتیبانی کامل از زبان‌های فارسی، انگلیسی، ترکی و روسی).
- نمایش شماتیک سیم‌بندی و پین‌های فیزیکی برد برای تکنسین برق بدون نیاز به نقشه چاپی.

---

## ۲. ساختار ۶ کارته مدال راهنما (6-Card Industrial Help Modal)

مدال راهنما به صورت تمام‌صفحه یا با ابعاد استاندارد ۴۵۲x۲۹۲ پیکسل طراحی شده و دارای ناوبری ورق‌زدن (Next / Prev) با کارت‌های مستقل است:

```
+-------------------------------------------------------------------------+
| [?] راهنمای جامع دستگاه گاز پرکن هافلر                      [X بستن]     |
+-------------------------------------------------------------------------+
|                                                                         |
|   +-----------------------------------------------------------------+   |
|   |                        CARD CONTENT AREA                        |   |
|   |                                                                 |   |
|   |   Card 1: مراحل گام‌به‌گام کار با دستگاه و نحوه ورود ابعاد       |   |
|   |   Card 2: انتخاب حالت‌های کاری (تکی، همزمان و پدال)             |   |
|   |   Card 3: نقشه سیم‌بندی پدال، سنسورها و استپ قارچی               |   |
|   |   Card 4: اتصالات شیرهای برقی، قطبیت N.O/N.C و اسنابرها         |   |
|   |   Card 5: کلیدهای ۱۰ گانه پنل جلو و کار بدون تاچ                |   |
|   |   Card 6: جدول خطاهای متداول، رفع عیب و کد قفل روزشمار          |   |
|   |                                                                 |   |
|   +-----------------------------------------------------------------+   |
|                                                                         |
|   [ < کارت قبلی ]             ( صفحه ۳ از ۶ )             [ کارت بعدی > ]|
+-------------------------------------------------------------------------+
```

### شرح تفصیلی محتوای کارت‌ها:
1. **کارت ۱: فرآیند تزریق گاز:**
   - نحوه اندازه گیری ابعاد شیشه و اسپیسر.
   - فرمول ساده تبدیل ابعاد به زمان تزریق.
   - نحوه استارت شیشه ۱ (راست) و شیشه ۲ (چپ).
2. **کارت ۲: انتخاب حالت‌های کاری:**
   - عملکرد کلید `MODE`.
   - تزریق نامتقارن (دو شیشه با ابعاد متفاوت در حالت همزمان).
   - نحوه کارکرد نوار پیشرفت درصد گاز.
3. **کارت ۳: نقشه ورودی‌ها و پدال:**
   - ترمینال پایه GPIO 7 برای اتصال پدال پایی صنعتی.
   - ترمینال پایه GPIO 3 برای استپ قارچی اضطراری.
   - تذکر در مورد منطق ورودی‌های Active-LOW ایزوله.
4. **کارت ۴: اتصالات شیرهای برقی گاز:**
   - پین GPIO 16 (شیر ۱ / شیشه ۲ چپ).
   - پین GPIO 42 (شیر ۲ / شیشه ۱ راست).
   - نحوه نصب مدار اسنابر موازی با بوبین شیرها.
5. **کارت ۵: کاربری بدون تاچ:**
   - راهنمای کلیدهای تابع F1 تا F5.
   - کلیدهای START, STOP, SAVE, CANCEL.
6. **کارت ۶: جدول عیب‌یابی و خطاها:**
   - اگر گاز تزریق نشد چه مواردی چک شود (کپسول، رگلاتور، اسنابر، فیوز رله).
   - علت خطای "ابعاد نامعتبر است".
   - نحوه دریافت کد بازگشایی قفل اقساط.

---

## ۳. استاندارد پیاده‌سازی در کد (`screens.c` / `actions.c`)

- فونت کارت‌ها: فونت استاندارد وزیر فارسی (یا Arial در حالت انگلیسی/روسی).
- عدم وجود کاراکترهای مربعی: کلیه نیم‌فاصله‌ها (ZWNJ) و کاراکترهای نامتعارف حذف شده و با متون تمیز روزمره جایگزین شده‌اند.
- خروج ایمن: کلید بستن (X) یا کلید فیزیکی `CANCEL` مدال را فوری می‌بندد و به داشبورد بازمی‌گردد.
