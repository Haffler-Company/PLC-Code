# مشخصات فنی و معماری وب‌اپلیکیشن صنعتی و اینترنت اشیا (Web Portal Specification)
## Industrial Web App, SoftAP Hotspot & Factory Telemetry — Gas Filling PLC

این سند تشریح‌کننده معماری، پروتکل‌های ارتباطی، نقاط پایانی (Endpoints) و سیستم گزارش‌گیری وب‌اپلیکیشن داخلی دستگاه گاز پرکن هافلر (`GasFilling_HMI/webportal.cpp`) است. این سیستم به اپراتورها و مدیران کارگاه اجازه می‌دهد بدون نیاز به کابل یا نصب هرگونه نرم‌افزار جانبی، دستگاه را از طریق مرورگر تلفن همراه، تبلت یا کامپیوتر پایش و تنظیم کنند.

---

## ۱. معماری شبکه و حالت‌های ارتباطی (Network Architecture)

دستگاه گاز پرکن مجهز به تراشه وای‌فای داخلی ESP32-S3 با پشتیبانی از دو حالت کاری مستقل است:

1. **حالت اکسس‌پوینت داخلی (SoftAP Mode - پیش‌فرض):**
   - نام شبکه (SSID): `Haffler-GasFiller-V1.8.x` (همگام با نسخه سفت‌افزار).
   - رمز عبور پیش‌فرض: بدون رمز (Open) جهت اتصال آسان و سریع در کارگاه.
   - آدرس IP پیش‌فرض دستگاه: `192.168.4.1`
   - کپتیو پورتال (Captive Portal): به محض اتصال تلفن همراه، صفحه مرورگر به صورت خودکار با قابلیت DNS Redirection باز می‌شود.

2. **حالت اتصال به شبکه کارخانه (Station Mode):**
   - دستگاه می‌تواند به اکسس‌پوینت یا روتر مرکزی کارگاه متصل شده و یک IP محلی در شبکه کارخانه دریافت کند.
   - وضعیت اتصال در هدر اصلی HMI نمایش داده می‌شود (خاموش: غیرفعال / آبی: هات‌اسپات فعال / سبز: متصل به وای‌فای کارخانه).

## ۲. فهرست نقاط پایانی وب‌سرور (REST API & Web Endpoints)

| مسیر (URI) | متد HTTP | نوع محتوا | شرح عملکرد |
|:---|:---:|:---:|:---|
| `/` | GET | `text/html` | صفحه داشبورد اصلی وب‌پورتال (طراحی ریسپانسیو مدرن هافلر) |
| `/api/status` | GET | `application/json` | ارسال زنده تله‌متری دستگاه: وضعیت ایستگاه‌ها، ابعاد، زمان تزریق، حافظه، بار CPU |
| `/api/config` | POST | `application/json` | دریافت و اعمال تنظیمات فرآیند: دبی جریان $Q_s$، فشار $P_1/P_2$، بازر، زبان |
| `/api/test_valve` | POST | `application/json` | تست دستی تحریک یا قطع شیرهای گاز (فقط در حالت توقف) |
| `/api/export_csv` | GET | `text/csv` | **دانلود مستقیم فایل اکسل/CSV آمار تولید و رکوردهای تزریق** |
| `/update` | GET | `text/html` | صفحه فرم آپلود فریمور جدید از طریق مرورگر |
| `/update` | POST | `multipart/form-data` | دریافت استریم باینری `firmware.bin` و فلش مستقیم روی پارتیشن OTA |
| `/reboot` | POST | `application/json` | راه‌اندازی مجدد ایمن دستگاه پس از ذخیره پارامترها |

## ۳. فرمت گزارش آمار تولید اکسل/CSV (`/api/export_csv`)

- این فایل مستقیماً در نرم‌افزارهای Microsoft Excel، Google Sheets و سامانه‌های ERP کارخانجات پنجره دوجداره باز می‌شود.

## ۴. ایمنی صنعتی در کنترل تحت وب

- **اینترلاک استارت شیرها:** دستورات شروع تزریق از وب تنها زمانی مجاز هستند که دستگاه در وضعیت عادی باشد و هیچ آلارم یا استپ اضطراری فعالی وجود نداشته باشد.
- **ایمنی حافظه رم:** سرور وب به صورت کاملاً غیرمسدودکننده (Asynchronous / Non-blocking) روی پورت ۸۰ اجرا شده و کمترین میزان حافظه استک را مصرف می‌کند تا هیچ تاخیری در حلقه گرافیکی ۵۰ فریم LVGL ایجاد نشود.
