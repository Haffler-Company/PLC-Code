# مشخصات و راهنمای کاربری ۱۰۰٪ بدون تاچ (Touchless Operation Specification)
## Haffler Industrial Argon Gas Filler — 10-Key Panel & Foot Pedal Control Directive

این مستند تشریح‌کننده کامل معماری، نحوه عملکرد و استانداردهای پیاده‌سازی کاربری بدون لمس صفحه (Touchless Mode) در سفت‌افزار دستگاه گاز پرکن هافلر است. در محیط‌های صنعتی و کارگاهی شیشه دوجداره (وجود گرد و غبار، دستکش‌های کارگری، چسب پلی‌سولفاید و رطوبت)، اپراتور باید قادر باشد تمامی امور تولید و ناوبری را بدون کوچک‌ترین نیاز به لمس صفحه انجام دهد.

---

## ۱. فلسفه طراحی و کنترل دوگانه (Dual-Input Redundancy)

سیستم کنترل بر پایه استانداردهای صنعتی زیمنس مجهز به افزونگی کامل ورودی‌هاست:
- تمامی عملکردها هم از طریق تاچ خازنی صنعتی GT911 و هم از طریق **۱۰ کلید فیزیکی جلو پنل + پدال صنعتی پایی** در دسترس هستند.
- در صورت شکستن یا از کار افتادن تاچ، عملکرد دستگاه در خط تولید حتی برای یک لحظه متوقف نمی‌شود.

```
+-------------------------------------------------------------------------+
|                              HMI FRONT PANEL                            |
|                                                                         |
|   +-----------------------------------------------------------------+   |
|   |                        480x320 ST7796 LCD                       |   |
|   |   [ Glass 2 - Left ]                       [ Glass 1 - Right ]  |   |
|   |   Progress: 45%                            Progress: Idle       |   |
|   +-----------------------------------------------------------------+   |
|                                                                         |
|   [ F1 ]      [ F2 ]      [ F3 ]      [ F4 ]      [ F5 ]                |
|   Main        General     Process     Test        Admin                 |
|                                                                         |
|   [ MODE ]    [ START ]   [ STOP ]    [ SAVE ]    [ CANCEL ]            |
|   Select St.  Inject      Emergency   Commit      Back/Close            |
+-------------------------------------------------------------------------+
       |
       +---> FOOT PEDAL (GPIO 7 - Optocoupled, Active-LOW)
       |
       +---> E-STOP BUTTON (GPIO 3 - Optocoupled, Active-LOW)
```

## ۲. مشخصات سخت‌افزاری و کانال‌های ADC کلیدها

کلیدهای فیزیکی از طریق نردبان تقسیم ولتاژ مقاومتی دقیق (Resistor Ladder) به دو کانال مبدل آنالوگ به دیجیتال (ADC) میکروکنترلر ESP32-S3 متصل هستند:

### ۲.۱. کانال کلیدهای تابع F1 تا F5 (پایه GPIO 1)
- پیکربندی پین: `analogSetPinAttenuation(PIN_KEY_F, ADC_11db);` (ورودی آنالوگ با تضعیف ۱۱ دسی‌بل جهت بازه کامل ۰ الی ۳.۳ ولت).
- ⚠️ **قانون سخت‌افزاری:** هرگز از `pinMode(PIN_KEY_F, INPUT_PULLUP)` استفاده نکنید؛ زیرا مقاومت پول‌آپ داخلی خطی بودن نردبان مقاومتی را برهم زده و مقادیر ADC را مخدوش می‌کند.

| کلید | بازه مجاز ADC (0..4095) | مقدار میانگین نامی | عملکرد سفت‌افزار |
|:---:|:---:|:---:|:---|
| **بدون فشردن** | > ۳۷۰۰ | ۴۰۹۵ | عدم فشردن کلید (`KEY_NONE`) |
| **F1** | ۳۱۰۰ الی ۳۶۰۰ | ۳۳۵۰ | بازگشت آنی به داشبورد اصلی (`SCREEN_ID_MAIN`) |
| **F2** | ۲۴۵۰ الی ۳۰۰۰ | ۲۷۰۰ | ورود به تنظیمات - زبانه ۱: تنظیمات عمومی (`tabview_setting`, index 0) |
| **F3** | ۱۷۰۰ الی ۲۳۰۰ | ۲۰۰۰ | ورود به تنظیمات - زبانه ۲: فرآیند و دبی گاز (`tabview_setting`, index 1) |
| **F4** | ۹۵۰ الی ۱۵۵۰ | ۱۲۵۰ | ورود به تنظیمات - زبانه ۳: تست دستی شیرها و I/O (`tabview_setting`, index 2) |
| **F5** | ۲۰۰ الی ۸۵۰ | ۵۰۰ | ورود به تنظیمات - زبانه ۴: مدیریت و قفل روزشمار (`tabview_setting`, index 3) |

### ۲.۲. کانال کلیدهای فرمان و کنترل (پایه GPIO 2)
- پیکربندی پین: `analogSetPinAttenuation(PIN_KEY_M, ADC_11db);`

| کلید | بازه مجاز ADC (0..4095) | مقدار میانگین نامی | عملکرد سفت‌افزار |
|:---:|:---:|:---:|:---|
| **بدون فشردن** | > ۳۷۰۰ | ۴۰۹۵ | عدم فشردن کلید (`KEY_NONE`) |
| **MODE** | ۳۱۰۰ الی ۳۶۰۰ | ۳۳۵۰ | جابجایی چرخشی سه‌حالته بین ایستگاه‌ها (Glass 1 $\to$ Glass 2 $\to$ Dual Sync) |
| **START** | ۲۴۵۰ الی ۳۰۰۰ | ۲۷۰۰ | استارت تزریق گاز در ایستگاه(های) فعال با نمایش Toast تایید |
| **STOP** | ۱۷۰۰ الی ۲۳۰۰ | ۲۰۰۰ | توقف اضطراری آنی فرآیند و قطع شیرهای گاز در کمتر از ۷۰ms |
| **SAVE** | ۹۵۰ الی ۱۵۵۰ | ۱۲۵۰ | ثبت مقادیر تنظیم شده در حافظه EEPROM پایدار (`a2_eeprom_write_all`) |
| **CANCEL** | ۲۰۰ الی ۸۵۰ | ۵۰۰ | بستن پنجره‌های باز، پاپ‌آپ‌ها، کیبوردها و بازگشت به صفحه اصلی |

## ۳. ورودی‌های دیجیتال اپتوکوپلری (پدال و استپ قارچی)

علاوه بر کلیدهای پنل، دو ورودی فیزیکی ایزوله صنعتی مستقیماً با وقفه نرم‌افزاری پردازش می‌شوند:

1. **پدال پایی صنعتی (GPIO 7 - PIN_OPTO_START):**
   - اتصال به صورت Active-LOW با پول‌آپ سخت‌افزاری و ایزولاسیون اپتوکوپلری.
   - عملکرد: دقیقاً معادل با فشردن کلید `START` پنل. با فشردن پدال، تزریق در حالت فعال کلید `MODE` فوراً آغاز می‌گردد.
   - مزیت اپراتوری: دست‌های کارگر برای نگه داشتن شیشه‌های سنگین دوجداره آزاد است و تزریق با پا کلید می‌خورد.

2. **استپ اضطراری قارچی (GPIO 3 - PIN_OPTO_STOP):**
   - اتصال به صورت Active-LOW با اولویت قطعی ۱ (Highest Priority Interrupt).
   - عملکرد: به محض فشرده شدن شستی قارچی یا باز شدن میکروسوئیچ حفاظتی، تابع `panel_keys_emergency_stop_all()` بدون درنگ اجرا شده و خروجی‌های GPIO16 (شیر ۱)، GPIO42 (شیر ۲) و GPIO45 (بازر) قطع قطعی می‌شوند.

## ۴. چرخه اسکن، فیلتر نویز و دیبانس (Debounce Algorithm)

اسکن کلیدها در فایل `panel_keys.cpp` داخل حلقه اصلی با مشخصات زیر اجرا می‌شود:
- فرکانس نمونه‌برداری: **۴۰ هرتز (دوره تناوب ۲۵ میلی‌ثانیه)**.
- اولویت پردازش: ورودی‌های دیجیتال سریع (پدال و استپ) قبل از خواندن ADC بررسی می‌شوند.
- لبه تحریک (Edge Detection): فرمان تنها با لبه پایین‌رونده کلید (تغییر از `KEY_NONE` به کلید معتبر) اجرا می‌شود تا نگه‌داشتن ممتد کلید باعث اجرای مکرر نشود.
- بازخورد صوتی: تمامی کلیدهای فیزیکی با فعال‌سازی ماکروی `buzzer_key` یک بیپ صوتی شفاف و کوتاه (۲۰ms) در فرکانس ۷ کیلوهرتز تولید می‌کنند.
