# ⚠️ CRITICAL PROJECT ACCURACY RULE

## NO GUESSING — NO UNVERIFIED DESIGN DECISIONS

This is an industrial PLC/HMI project with potential safety and production consequences. The user does not accept mistakes, guesses, assumptions presented as facts, or unverified component/design recommendations.

Before making any recommendation, calculation, schematic change, component selection, or approval:

1. Verify the exact part number, marking, polarity, package, and value from the original Altium source or an authoritative datasheet.
2. Never read or infer a value from an unclear screenshot when the source file can be checked.
3. Separate `Verified`, `Calculated`, `Assumption`, `Unknown`, and `Not Verified` information.
4. Check absolute maximum ratings, operating limits, tolerances, temperature, transient behavior, lifecycle, sourcing, and relevant standards.
5. Recalculate the complete circuit under minimum, nominal, maximum, fault, startup, and temperature conditions.
6. If any required information is missing or ambiguous, stop and state the exact missing item. Do not fill the gap by guessing.
7. Every downloaded file must be checked for correct file type, valid signature, successful opening, source URL, revision, and date.
8. Do not call a component available in Iran unless the current supplier page explicitly shows available stock; `out of stock` must be recorded as unavailable.
9. Do not approve a design for production based only on a reference schematic, marketplace listing, simulation, or typical value.
10. Any detected error must invalidate the affected conclusion until it is rechecked from the primary source.

**Accuracy and traceability take priority over speed.**
