# Haffler Double-Head Digital Cutter (اره برش دوسر دیجیتال هافلر)
## مدل: HAFFLER DC-900 | برد صنعتی ETV3A (ESP32-S3 N16R8)

پروژه سیستم کنترل صنعتی و HMI دستگاه اره برش دوسر دیجیتال با قابلیت برش همزمان دو سر پروفیل‌های آلومینیوم و UPVC، مجهز به انکودر موقعیت خطی، تصحیح لقی دنده‌شانه، کاتینگ لیست هوشمند و زاویه‌گیر خودکار ۴۵/۹۰/۱۳۵ درجه.
