# راهنمای سیم‌بندی و پین‌اوت برد کنترلر صنعتی هافلر (HT-V3A)

این سند مرجع رسمی و فنی سیم‌بندی تابلوی برق، اتصالات سنسورها، رله‌ها و استپر موتور برای دستگاه اره تک‌سر و متر دیجیتال هافلر بر پایه کنترلر ESP32-S3 است.

---

## ۱. مشخصات عمومی برد کنترلر
* **پردازنده:** ESP32-S3-WROOM-1 / DevKitC-1 (16MB Flash, 2MB/8MB PSRAM)
* **منطق خروجی رله‌ها:** Active LOW (سطح صفر منطقی = رله وصل)
* **تغذیه:** ۲۴ ولت صنعتی ایزوله شده (با رگولاتورهای داخلی ۵ ولت و ۳.۳ ولت)
* **نمایشگر:** ۴ اینچ ۴۸۰×۳۲۰ تمام رنگی با درایور ILI9341 و ارتباط SPI با کلاک ۴۰ مگاهرتز
* **تاچ پنل:** خازنی صنعتی (I2C بر پایه باس اشتراکی با RTC دقیق DS3231)

---

## ۲. جدول خروجی‌های رله (Relay Outputs)

| نام خروجی | شماره رله | پین ESP32 | منطق تحریک | وظیفه در دستگاه |
|:---:|:---:|:---:|:---:|:---|
| **Q0** | Relay 1 | `GPIO 16` | Active LOW | جک گیره افقی ۱ (Horizontal Clamp 1) |
| **Q1** | Relay 2 | `GPIO 42` | Active LOW | جک گیره عمودی ۲ (Vertical Clamp 2) |
| **Q2** | Relay 3 | `GPIO -1` | - | رزرو / نصب نشده |
| **Q3** | Relay 4 | `GPIO 48` | Active LOW | موتور اره دیسکی (Blade Motor On/Off) |
| **Q4** | Relay 5 | `GPIO -1` | - | رزرو / نصب نشده |
| **Q5** | Relay 6 | `GPIO 15` | Active LOW | خروجی کمکی / SSR اره |
| **Q6** | Relay 7 | `GPIO 35` | Active LOW | پاشش مایع خنک‌کننده آب‌صابون (Coolant Mist) |
| **Q7** | Relay 8 | `GPIO 36` | Active LOW | حفاظ و گارد ایمنی اپراتور (Safety Guard) |
| **Q8** | Relay 9 | `GPIO 38` | Active LOW | جک بالابرنده تیغه اره (Blade Lift Cylinder) |
| **Q9** | Relay 10| `GPIO 41` | Active LOW | خروجی کمکی قابل برنامه‌ریزی ۹ |
| **BUZZ**| بازر صوتی| `GPIO 45` | PWM/Digital | بازر هشدار و فیدبک کلیدهای لمسی و پنل |

## ۳. جدول ورودی‌های سنسورها و کلیدهای پنل (Inputs)

| پین ESP32 | نوع سیگنال | ولتاژ | وظیفه و توضیحات |
|:---:|:---:|:---:|:---|
| `GPIO 1` | آنالوگ ADC | 0 - 3.3V | **لدر کلیدهای تابع (F-Keys):** تفکیک ولتاژی کلیدهای F1 تا F5 پنل با مقاومت‌های دقیق |
| `GPIO 2` | آنالوگ ADC | 0 - 3.3V | **لدر کلیدهای اصلی پنل:** SAVE (ذخیره)، CANCEL (انصراف)، MODE (تغییر حالت)، START و STOP |
| `GPIO 3` | دیجیتال/ADC | 0 - 3.3V | **میکروسوئیچ برش و زاویه ۹۰ درجه:** ورودی سنسور تشخیص زاویه گونیا یا لیمیت اره |
| `GPIO 4` | آنالوگ ADC | 0 - 3.3V | **سنسور جریان و خطای موتور اره:** فیدبک اضافه جریان، برگشت تیغه و اضافه بار |
| `GPIO 5` | آنالوگ ADC | 0 - 3.3V | **کلید استاپ اضطراری (E-Stop) و سنسور گارد:** نظارت دائم بر سلامت حلقه ایمنی |
| `GPIO 6` | آنالوگ ADC | 0 - 3.3V | **سنسور مرجع و شروع خط (Homing Reference):** سنسور القایی ابتدای مسیر متر |
| `GPIO 21`| ورودی پول‌آپ | 3.3V | **جویستیک جهت چپ / T1:** حرکت دستی به سمت عقب (Active LOW با دیبانس ۳۰ms) |
| `GPIO 37`| ورودی پول‌آپ | 3.3V | **جویستیک جهت راست / T2:** حرکت دستی به سمت جلو (Active LOW با دیبانس ۳۰ms) |
| `GPIO 7` | ورودی دیجیتال | 3.3V | **شستی برش دو دستی (Start 2):** ورودی شستی دوم ایمنی برش |

## ۴. اتصالات استپر موتور و درایور صنعتی

| سیگنال درایور | پین ESP32 | توضیحات |
|:---:|:---:|:---|
| **PUL+ / STEP** | `GPIO 47` | ارسال پالس‌های فرکانسی حرکت متر (تا ۱۰۰ کیلوهرتز) |
| **DIR+ / DIR** | `GPIO 21` | تعیین جهت چرخش شفت موتور (جلو / عقب) |
| **ENA+ / ENABLE**| `GPIO 39` | فعال‌سازی درایور (Active LOW؛ در صورت بروز فالت آزاد می‌شود) |
| **PUL- / DIR- / ENA-**| `GND` | اتصال مشترک کاتد به زمین ایزوله شده ۲۴ ولت |

## ۵. باس‌های ارتباطی I2C و SPI نمایشگر

| پین ESP32 | نام سیگنال | ماژول‌های متصل |
|:---:|:---:|:---|
| `GPIO 8` | I2C SDA | خط داده سنسور تاچ خازنی FT6236/GT911 + ماژول ساعت DS3231 |
| `GPIO 9` | I2C SCL | خط ساعت باس I2C (دارای مقاومت پول‌آپ ۲.۲k و نرخ ۱۰۰kHz) |
| `GPIO 40`| TOUCH INT | وقفه لمس تاچ پنل |
| `GPIO 39`| TOUCH RST | ریست سخت‌افزاری آی‌سی تاچ |
| `GPIO 10`| SPI MOSI | ارسال داده تصویر به درایور ILI9341 نمایشگر |
| `GPIO 11`| SPI MISO | دریافت داده تصویر / فریم‌بافر |
| `GPIO 12`| SPI SCLK | کلاک سریال نمایشگر (۴۰ مگاهرتز استاندارد صنعتی) |
| `GPIO 13`| LCD CS | پایانه انتخاب چیپ نمایشگر (Chip Select) |
| `GPIO 14`| LCD DC | انتخاب دستور یا داده تصویر (Data / Command) |

---

## ۶. پورت‌های سریال (UART) و عیب‌یابی

* **UART0 (`TX=43`, `RX=44`):** ارتباط با مبدل CP210x به پورت USB کامپیوتر با باودریت **921600** جهت اسکرین‌شات زنده زیر ۳ ثانیه، انتقال فریم‌بافر، لاگ تشخیصی و عیب‌یابی مانیتور.
* **UART2 (`GPIO 17`, `GPIO 18`):** پورت خروجی چاپگر رسید حرارتی (Thermal Printer ESC/POS).
