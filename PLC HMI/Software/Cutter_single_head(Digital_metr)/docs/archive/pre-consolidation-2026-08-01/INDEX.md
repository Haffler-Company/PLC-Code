# Documentation Index

Read by task, never as a bundle.

## Active

- `AGENTS.md`: binding operating contract.
- `docs/AGENT_START_HERE.md`: selective reading map.
- `docs/PROJECT_NOTES.md`: hardware, task, source, and build facts.
- `docs/PROJECT_RULES.md`: source protection, artifacts, and workflow.
- `docs/TECHNICAL_KNOWLEDGE.md`: concise current lessons and risks.
- `docs/WORK_ITEMS.md`: active tasks; search instead of reading completed history.
- `docs/SKILLS_AND_TOOLS.md`: tools and commands.
- `docs/SCENARIO_FA.md`: machine behavior and hardware tests.
- `docs/SIMULATOR_FA.md`: simulator-only work.

## Historical/reference

`docs/archive/` contains completed audits, superseded technical notes, and historical plans. It is retained for provenance, but must not be loaded at task start.
