# حقیقت شبیه‌ساز — برای عامل و مالک

## اشتباه ممنوع (تکرار نشود)

مالک خواست: **کد UI بدون PLC اجرا شود**، داخل بخش‌ها برود، باگ کد را ببیند، ظاهر عین LCD.

**نمایش SHOT / عکس PNG داخل HTML = شبیه‌ساز کد نیست.** فقط آینهٔ پیکسل مرده است. ساختن/فروختن آن به‌جای شبیه‌ساز، اتلاف وقت و اعصاب مالک است.
