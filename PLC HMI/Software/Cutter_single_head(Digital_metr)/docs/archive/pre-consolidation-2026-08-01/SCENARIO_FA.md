# سناریوی کامل دستگاه — Metr & Cutter V.1.6.22
> **مرجع رفتار صحیح (هم‌تراز فریمور فعلی).** اگر در تست رفتاری غیر از این دیدید، فقط شمارهٔ بند را بگویید (مثلاً «بند 4.3 مشکل دارد») — سناریو اینجاست و لازم نیست توضیح بدهید.

## 1. بوت
- 1.1 اسپلش: عکس تمام‌صفحه از SPIFFS (`/splash0.rgb565` یا `/splash1.rgb565`، نوبتی هر بوت) ~۳ ثانیه؛ روی آن نسخهٔ FW نمایش داده می‌شود. اگر عکس نبود → زمینهٔ ساده + متن نسخه.
- 1.2 سلف‌تست سخت‌افزاری کامل روی اسپلش ممکن است ناقص/حذف‌شده باشد؛ سلامت بوت از لاگ سریال (`CHK1`… / `T2 create=1`) و ورود به صفحهٔ موقعیت‌یابی تأیید می‌شود.
- 1.5 **مانیتور دما:** هر 10 ثانیه دمای داخلی تراشه؛ بالای 75°C → توست تهویه + بوق (یک‌بار؛ بعد از زیر 65°C دوباره مسلح).
- 1.3 بعد از اسپلش → صفحهٔ موقعیت‌یابی (main_0).

## 2. موقعیت‌یابی (رفرنس)
- 2.1 دکمهٔ سبز یا Enter کیبورد → **دو مرحله** (از V.1.6.13): ۱) رویکرد به سنسور ابتدا ۲) خزش برگشت تا رهاشدن سنسور و ثبت صفر. **مرحلهٔ سوم نزدیک‌شدن مجدد وجود ندارد.**
- 2.2 هر مرحله timeout ‏30s → پیام خطای رفرنس. برخورد به سنسور انتها حین رفرنس → پیام «جهت موتور اشتباه است».
- 2.3 موفقیت یا تأیید «بله» → صفحهٔ اصلی؛ `referenced` مسلح می‌شود.

## 3. صفحهٔ اصلی (main_1)
- 3.1 عدد بزرگ = موقعیت فعلی (سبز=در مقصد، قرمز=خارج مقصد). لمس آن حین حرکت = توقف حرکت.
- 3.2 setpoint بالا-چپ: تایپ با کیبورد USB یا **لمس خود عدد → نامپد لمسی**. Enter/✔ → clamp به [طول اولیه..حداکثر] — اگر خارج محدوده بود **توست خطا + بوق** — سپس حرکت.
- 3.3 جوگ: جوی‌استیک یا کلید 4/6 (NumLock=jog). رمپ نرم؛ رهاکردن = توقف نرم؛ **استوپ = توقف فوری**. روی سنسور ابتدا/انتها: حرکت **به سمت خروج** مجاز است (`limit_escape_sensor` + `stepperStopRequested`)؛ حرکت عمیق‌تر به همان سنسور ممنوع.
  - **خط قرمز:** فریز رها = V.1.6.19؛ حرکت چپ به مقصد: لقی ۵mm رد + برگشت روی مقصد (راست بدون لقی).
- 3.3b **کلید START پنل (آنالوگ pin2):** حرکت به مقصد / عدد بعدی لیست یا بهینه؛ در جاگ = توقف نرم. **استارت ۱ و ۲ فقط برش** (دو‌دست / تأیید) — به حرکت استپر وصل نیستند.
- 3.3c شمارندهٔ کوچک «شیفت N» پایین‌چپ = `user_cuts` (قابل ریست از F5/وب)؛ نه شمارندهٔ عمری.
- 3.4 برخورد به سنسور ابتدا/انتها → **مودال روی لایهٔ top** (متن فارسی/انگلیسی + تأیید/X). **تایمر خودکار ~۷s ندارد** — تا تأیید اپراتور می‌ماند. تا باز بودن مودال: `lock_screen` + قفل پالس. بعد از تأیید: اجازهٔ دور شدن از همان سنسور.
- 3.5 دکمهٔ «ردیف بعد»: انتخاب ردیف بعدی لیست؛ آخر لیست → پیام پایان.
- 3.6 میانبرهای F1..F5 روی اصلی: یادآوری/اعمال مقصد ذخیره‌شده (رفتار رسمی محصول).

## 4. لیست برش (main_3) — 50 ردیف
- 4.1 پنج صفحهٔ 10تایی؛ دکمه‌های **◀ ▶** و شمارندهٔ «1/5» در هدر. **سوایپ** روی محدودهٔ کادرها هم صفحه را عوض می‌کند. تعویض صفحه وسط ادیت = لغو ادیت.
- 4.2 «+»/«−» تعداد ردیف فعال (0..50). ردیف تازه‌ساخته همیشه سایز=0 و تعداد=0. اگر از صفحه بیرون بزند، صفحه خودکار عوض می‌شود.
- 4.3 لمس متراژ → ادیت (آبی) + نامپد؛ ✔ متراژ → خودکار ادیت تعداد همان ردیف؛ ✔ تعداد → پایان. × نامپد = لغو با برگرداندن مقدار قبلی. خارج محدوده → توست + clamp.
- 4.4 لمس پنل سبز ردیف → انتخاب برای برش (آبی می‌شود) → صفحهٔ اصلی با متراژ آن ردیف.
- 4.5 مود لیست: هر برش تأییدشده شمارش را کم می‌کند؛ صفر → **ردیف بعدیِ دارای شمارش خودکار لود** + بوق (حرکت فقط با Enter اپراتور)؛ اتمام کل → پیام پایان + بوق.
- 4.6 **دکمهٔ سطل قرمز** (هدر، کنار +): دیالوگ تأیید → صفرکردن تعدادِ همهٔ ردیف‌ها (متراژها می‌مانند) + توست. حین برش یا بهینه‌سازی فعال، رد می‌شود. (NVS تکه‌تکه — نباید هنگ کند.)

## 5. بهینه‌سازی برش (دکمهٔ نارنجی «بهینه برش»)
- 5.1 ورودی: ردیف‌های فعال (متراژ×تعداد). تنظیمات مؤثر: **طول شاخه، پرت تیغه (kerf)، پیش‌برش** — از پنل بهینه، تنظیمات F1، یا وب‌پورتال.
- 5.2 الگوریتم FFD: قطعات نزولی مرتب و در اولین شاخهٔ جادار چیده می‌شوند؛ هر برش kerf مصرف می‌کند. سقف 240 قطعه/60 شاخه.
- 5.3 پنل نتیجه: تعداد شاخه + پرت کل + قطعهٔ جاری (قرمز درشت) + لیست شاخه‌به‌شاخه با پرت هر شاخه؛ شاخهٔ جاری هایلایت نارنجی.
- 5.4 اجرا: «حرکت به قطعه» (فقط وقتی رفرنس‌شده و موتور ساکن) → محور می‌رود → برش دومرحله‌ای عادی (دو دست + محافظ) → تأیید برش = جلورفتن صف + کم‌شدن تعداد ردیف مبدأ → دوباره «حرکت به قطعه». «رد کردن» = پرش. «خروج» = بستن.
- 5.5 پایان صف → توست «بهینه‌سازی تمام شد» + بوق.
- 5.6 خطاها: ردیف بلندتر از شاخه (با شمارهٔ ردیف)، لیست خالی.
- 5.7 **تنظیم روی خود پنل:** سه ردیف [−]/[+]: «شاخه» (گام 100)، «پرت تیغه» (گام 1)، «پیش‌برش» (گام 10، بازه 0..500). هر تغییر = ذخیره + بازچینی فوری. اگر چینش جدید ممکن نبود → توست علت + بسته‌شدن پنل.
- 5.8 **پیش‌برش (trim):** طول مفید هر شاخه = شاخه − پیش‌برش (برش تمیزکاری سر شاخه — الگوی TigerStop/CutLogic). این برش در صف نمی‌آید؛ اپراتور خودش سر شاخه را می‌زند.
- 5.9 **لیبل پرینت در مود بهینه‌سازی:** بعد از هر تأیید برش، پرینتر «طول B شمارهٔ‌شاخه» چاپ می‌کند (مثل `2500 B3`) — برای ردیابی قطعات. خارج از بهینه‌سازی مثل قبل فقط طول.

## 6. سیکل برش (بدون تغییر نسبت به منطق اصلی)
- 6.1 دو استارت هم‌زمان = شروع سیکل: گیرهٔ جلو، ارهٔ روشن (اگر خاموش بود صبر «تایمر آماده‌سازی»)، محافظ باید تا 5s پایین بیاید وگرنه قطع + پیام محافظ.
- 6.2 رهاکردن استارت‌ها = پایان مرحله؛ اسپری 2s بعد خاموش. یک استارت تکی بعد = **تأیید برش** (پرینت + شمارنده‌ها).
- 6.3 استوپ در هر لحظه/هر صفحه = `force_estop_outputs_safe`: قطع همهٔ خروجی‌ها (اره، اسپری، بالابر، گیره‌ها، لامپ، Q9) + `mvm_interupt` + **قطع EN درایور استپر** + توقف تایمر پالس. حین نگه داشتن استاپ، حلقهٔ Task8 همین مسیر را تکرار می‌کند.

## 7. تنظیمات (main_2)
- 7.1 ورود فقط وقتی: برش فعال نیست، اره خاموش، گیره آزاد، تأیید برش معلق نیست، موتور ساکن — وگرنه بوق.
- 7.2 کلیدهای پنل: SAVE/CANCEL **هنگام رهاکردن** عمل می‌کنند. نگه‌داشتن 5s: CANCEL → دیالوگ ریست فکتوری؛ SAVE → دیالوگ پورتال WiFi.
- 7.3 F1: کیبرد مجازی، **عرض تیغه/پرت**، **طول شاخه**، دکمهٔ **وب اپ**.
- 7.4 خروج از تب تست = خاموشی خروجی‌های تست.

## 8. وب‌پورتال (دکمهٔ وب اپ در تنظیمات، یا SAVE نگه‌داشته → START)
- 8.1 AP: SSID معمولاً `ESP32-UPLOAD` — **رمز باز (بدون پسورد)** در فریمور فعلی. بعد از اتصال گوشی، captive DNS؛ دستی: `http://192.168.4.1`.
- 8.2 بالای صفحه: نسخهٔ FW + شمارندهٔ کل برش‌ها.
- 8.3 تنظیمات (نیاز PIN، پیش‌فرض 1234): سرعت‌ها٪، تایمر اره، حداکثر طول، **طول شاخه، kerf، trim**، بازر، جهت، تعداد ردیف، **۵۰ ردیف لیست**. Save → اعمال فوری + ذخیره. حین حرکت/برش → «busy».
- 8.4 **ایمپورت فایل سایز:** انتخاب .txt/.csv → «Load file» → فرم‌ها پر می‌شوند → Save. فرمت: هر خط `2500X10` یا CSV «متراژ,تعداد». اکسل → Save As CSV.
- 8.5 OTA: فایل firmware.bin + PIN → نوار پیشرفت → ری‌استارت.
- 8.6 پورتال تا ری‌استارت روشن می‌ماند.

## 9. ایمپورت سایز از سریال (UART0 / CP2102)
- 9.1 اتصال: TX0/RX0 ای‌اس‌پی ↔ CP2102 ↔ کامپیوتر، baud **115200**.
- 9.2 ارسال متن سایزها (همان فرمت `2500X10,1800X5,…` — تا 50 جفت). بعد از 400ms سکوت پارس می‌شود.
- 9.3 معتبر → روی HMI دیالوگ «Serial Size List: n rows — IMPORT/NO» + بوق. IMPORT → جایگزینی ردیف‌های 1..n + تعداد ردیف فعال = n + توست. NO → دورریختن (سریال «CANCELLED» می‌گوید).
- 9.4 پاسخ‌های سریال: `OK: n pairs` / `ERR: no valid…` / `IMPORTED`.
- 9.5 **محدودیت فنی:** CP2102 پل USB↔UART است و فلش USB را مستقیم نمی‌خواند؛ فایل باید از کامپیوتر/گوشی با ترمینال سریال ارسال شود.
- 9.6 تست: PuTTY/Termite روی پورت CP2102 با 115200 → متن `2500X10,1800X5` را بفرستید → دیالوگ باید بیاید.

## 10. ریست فکتوری
- 10.1 CANCEL پنل 5s در تنظیمات → بوق → دیالوگ (YES قرمز/NO سبز) → YES = پاک‌شدن تمام NVS (کالیبراسیون، لیست، شمارنده، PIN) + ری‌استارت.

## 11. صداها (بازر)
کوتاه = تأیید عمل | بلند = خطا/هشدار/رد عمل | پایان رفرنس: کوتاه | پایان حرکت: بلند | پایان لیست/بهینه‌سازی/پیام کالیبراسیون: بلند.

## چک‌لیست تست اپراتور (یک‌صفحه)

1. **بوت** → اسپلش → صفحهٔ موقعیت‌یابی بدون صفحه سیاه.
2. **رفرنس** یا «بله» → ورود به اصلی؛ عدد موقعیت زنده.
3. **جاگ** هر دو جهت → رهاکردن می‌ایستد؛ استوپ فوری قطع می‌کند.
4. روی **حداقل/سنسور اول**: جاگ یا Enter به سمت دور شدن باید حرکت کند (گیر نکند).
5. **Enter** به مقصد داخل محدوده → حرکت و توقف در مقصد (سبز).
6. **برش خشک** (اگر ایمن): دو استارت → استوپ قطع خروجی‌ها.
7. **لیست**: صفحه بعد/قبل، ادیت یک ردیف، انتخاب ردیف → اصلی.
8. **بهینه**: باز/بستن پنل بدون هنگ لمس.
9. مودال سنسور (اگر پیش آمد): تأیید → قفل باز → دوباره حرکت خروج ممکن.
