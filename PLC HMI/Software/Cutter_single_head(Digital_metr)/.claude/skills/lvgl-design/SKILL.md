# LVGL 9.4 design — 480x320 4" HMI (metr-and-cutter)

## Hard facts
- Display 480x320 landscape, LV_COLOR_DEPTH 16, LVGL **9.4** (v9 API: `lv_button_*`, `lv_display_*`, no v8 names).
- LVGL heap = BUILTIN pool 256KB in **PSRAM** (`config/lv_conf.h`). Never switch back to CLIB malloc — internal RAM starves and Task4/8/9 key tasks fail to start (all keys dead). Watch CHK8/CHK9/CHKa in boot log; CHKa < CHK9 = tasks OK.
- All LVGL calls only from Task2 (LVGL thread). Cross-task UI = set flags/pending vars, act in a tick (`update_flow_tick()` pattern). Never delete an object inside its own event callback (use-after-free) — set a flag, delete in tick.
- Screen switch: `request_goto_screen()` → `GUI.pending_goto_scr` → Task2.
- EEZ generates `include/ui/screens.h` (MAIN_0..3). Hand-coded UI lives in `include/app/ui_extras.h` (5400 lines) and self-contained overlay files like `include/app/update_flow.h` — overlays survive EEZ regen; prefer that pattern for new screens.

## Fonts / Persian
- Fonts: `ui_font_naz18b/naz24` (Persian text), `ui_font_digit40/100/120` (digits). naz lacks Persian digits U+06Fx → use **Arabic-Indic U+0660-0669**.
- FA/EN toggle pattern: reuse `f1_mk_mini_flag(parent, kind)` (0=Iran, 1=UK) from ui_extras.h.

## 480x320 layout rules (learned)
- Touch targets ≥ 48px; numpad = individual `lv_button`s in 3x4 grid (NOT lv_buttonmatrix), bottom row dot/zero/backspace, full-width green confirm, power-icon exit top-right.
- Big readouts: digit100/120 fonts clip easily — size labels explicitly, check with screenshots; avoid shadows on large objects (rendering cost/artifacts — see safe_shadow builds).
- LIST_ROWS_PER_PAGE = 5. LIST_MAX ≤ 50 (NVS partition overflows above).

## Verify loop (always do after UI change)
1. ONE build only: kill ALL pio.exe + xtensa-*-gcc + cc1* + scons python first (user IDE auto-builds collide; orphans corrupt .o). pio: `C:\Users\Haffler\.platformio\penv\Scripts\pio.exe`.
2. Flash: COM4 must be free (kill python holding it). Env `PYTHONIOENCODING=utf-8 PYTHONUTF8=1`.
3. Screenshot: `python tools/hmi_screenshot.py --port COM4 --out x.png` (~40s). Serial cmds SHOT/SCR1-3 in Task2. Reset: DTR False, RTS True→False.
4. Inspect PNG, iterate. Small coordinate tuning: batch several tweaks per flash cycle.

## RTL/bidi digit entry (solved 2026-07-14)
- LVGL bidi (LV_USE_BIDI=1, base RTL) classifies Arabic-Indic digits U+0660-0669 as an RTL run → whole run renders reversed even with style base_dir LTR. Fix: keep an ASCII shadow buffer; render FA display string REVERSED so on-screen order is LTR. EN renders buffer directly. Language toggle = re-render from buffer (converts glyphs+font).
- Textarea "jumps" while typing = add_char/add_text scroll-to-cursor. Fix: full `lv_textarea_set_text` rebuild + `lv_obj_scroll_to(ta,0,0,LV_ANIM_OFF)` each key.

## WiFi scan on ESP32-S3
- `WiFi.softAPdisconnect()` on a COLD (never-started) driver starts wifi with an unconfigured AP → LoadProhibited crash in `wifi_softap_start` (ppTask core0). Guard: only call it when `WiFi.getMode()` is AP/APSTA.
- `WiFi.scanNetworks()` fails after a half-finished `WiFi.begin` → always `WiFi.disconnect(false,false)` + ~200ms delay before scan; retry ≤3 with mode(WIFI_STA) between tries.

## Remote debug/verify (COM4)
- SERIAL_DEBUG_BAUD = **921600** (main.ino). Boot-ROM log is 115200; after `Serial0.begin` switch to 921600 or you read garbage.
- `Serial` = USB-CDC (invisible; USB is host-mode for keyboard). Debug prints must go to **Serial0** to be seen on COM4.
- Serial cmds (handled in serial_import.h + screenshot.h): SHOT (base64 RGB565 480x320), SCR1-3, UPD1(pw screen) UPD2(wifi) UPD3(type 123) UPD4(toggle lang).
- Screenshot client: scratchpad shot.py pattern — open port with dtr=False/rts=False (no reset), send SHOT, decode base64 rows (960B/row no padding).

## Update screen v2 (2026-07-14)
- Two model cards (برش/کانفیگ) with embedded RGB565 images (`include/app/uf_images.h`, generated by PIL → lv_image_dsc_t, LVGL9 header needs .magic/.cf/.stride). OTA models: `upvc/firmware_digital_cutter_single_head`, `upvc/firmware_config`.
- naz fonts have NO ASCII digits → version/percent text must use montserrat labels; FA status strings with %d → convert digits to U+0660-0669 before set_text.
- `lv_obj_set_pos` on lv_keyboard landed wrong — use `lv_obj_align(kb, LV_ALIGN_BOTTOM_MID,0,0)`. Full kb: TEXT_LOWER mode + 480x196 + montserrat_18 items = all letters/digits/symbols via built-in ABC/1# keys.
- Debug serial cmds now UPD1..5 (5 = update screen direct, 3 in wifi = open pass panel); TAB1..5 after SCR2 selects settings tab (handled in BOTH screenshot.h and serial_import.h — import task owns UART0 after ~8s).

## F5 dev page pattern (admin_ui.h, layout ver 4)
- Never mix Latin/digits into naz strings — every info line = caption label (naz, gray, top) + value label (montserrat, bottom) inside a cell; count tiles use montserrat_20 values. `f5_set_cap()` switches caption font/text per language.
- Smart touches: temp value color-coded (≥60 red, ≥45 orange), resettable tile marked with LV_SYMBOL_REFRESH, update button with LV_SYMBOL_DOWNLOAD icon at LEFT_MID.
- Bump F5_LAYOUT_VER to force rebuild of cached layout; null ALL static label pointers in the delete branch.

## Pitfalls log
- ui_extras.h gets swapped between versions mid-session by user/other sessions → before every build re-check `ls -la include/app/ui_extras.h`; ui_compat.h shim must match (duplicate-definition ⇄ undefined-reference flip-flop).
- `pinMode(1, INPUT_PULLUP)` breaks the analog F-key ladder — must be plain INPUT.
- Declare enums/consts ABOVE first use in ui_extras.h (single-header, order matters).
- New Arduino libs (HTTPClient etc.) need `lib_deps`, not just `-I`.
- User edits concurrently — before editing ui_extras.h/main.ino, re-read the touched region.
