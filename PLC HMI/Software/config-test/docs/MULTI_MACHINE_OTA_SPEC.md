# مشخصات فنی و معماری موتور نصاب و به‌روزرسانی چندماشینه OTA
## Multi-Machine OTA Installer & Cloud Distribution Engine — Haffler Config Launcher

این سند تشریح‌کننده معماری، پروتکل‌های دانلود ابری، مدیریت باکت‌های آروان‌کلود، فرآیند اعتبارسنجی هش SHA-256 و نحوه فلش مستقیم فریمور ماشین‌های مختلف شرکت هافلر بر روی برد **ESP32-S3 HT-V3A** است.

---

## ۱. نقش محوری لانچر کانفیگ (Unified Fleet Installer)

لانچر کانفیگ قلب تپنده خط مونتاژ و خدمات پس از فروش هافلر است. تمامی بردهای تولیدی ابتدا با فریمور `config-test` فلش می‌شوند. سپس تکنسین با اتصال دستگاه به وای‌فای کارگاه و ورود رمز **۱۲۳**، نوع ماشین مشتری را از لیست انتخاب کرده و دستگاه در کمتر از ۴۰ ثانیه فریمور نهایی آن ماشین را از سرور دانلود و فلش می‌کند:

```

                               |     HAFFLER OTA SERVER      |
                               |    (ArvanCloud S3 Bucket)   |
                               |    ota.haffler-infi.ir      |
                               +-----------------------------+
                                     |             |
                         lastfile    |             |  firmware
                     (Release Info)  |             |  (Binary)
                                     v             v
+-------------------------------------------------------------------------+
|                  HAFFLER CONFIG LAUNCHER (ESP32-S3)                     |
|                                                                         |
|   Select Target Machine:                                                |
|   [1] Digital Cutter Single-Head (برش تک‌سر / دیجیتال متر)                |
|   [2] Digital Cutter Double-Head (برش دوسر اتوماتیک)                     |
|   [3] Welding Single-Head (جوش تک‌سر پروفیل UPVC)                        |
|   [4] Welding Four-Head (جوش چهارسر اتوماتیک)                            |
|   [5] Argon Gas Filling (دستگاه تزریق گاز آرگون شیشه دوجداره)             |
|   [6] Ice Cream Maker (دستگاه بستنی‌ساز صنعتی)                           |
|   [7] Dough Divider (دستگاه چانه‌گیر نانوایی)                            |
|   [8] Corner Cleaning Machine (دستگاه گوشه‌تمیزکن)                       |
|   [9] End Milling Machine (دستگاه فرز سرپروفیل)                          |
+-------------------------------------------------------------------------+
                                     |
                                     | 1. SHA-256 Hash Match Check
                                     | 2. Flash to app0 OTA Partition (0x10000)
                                     | 3. Preserve NVS (0x9000)

                 [ REBOOT INTO TARGET MACHINE FIRMWARE ]
```

## ۲. مشخصات و ساختار باکت سرور ابری (ArvanCloud Object Storage)

- **دامنه سرور مرکزی:** `https://ota.haffler-infi.ir`
- **باکت ذخیره‌سازی ابری:** نام باکت `ota-plc` مستقر در منطقه `ir-thr-at1` آروان‌کلود.
- **فرمت نام‌گذاری کلید آبجکت‌ها (URL-Encoded):**
  کاراکتر اسلش (`/`) با `%2F` کدگذاری می‌شود:
  `https://ota.haffler-infi.ir/upvc%2F<machine-name>%2F<file>`
  - `<machine-name>`: نام استاندارد ماشین در جدول پروژه‌ها (مانند `digital-cutter-single-head`, `welding-single-head`, `gas-filling`, `config-test`).
  - `<file>`: دقیقاً یکی از دو فایل زیر است:
    1. `lastfile`: فایل متنی حاوی اطلاعات نسخه، متراژ، هش و لاگ تغییرات.
    2. `firmware`: فایل باینری فریمور پایدار (به صورت خام و **بدون پسوند .bin** بر روی سرور ذخیره می‌شود).

## ۳. فرآیند گام‌به‌گام دانلود و فلش ایمن (Fail-Safe OTA Flow)

1. **ارتباط شبکه و اسکن وای‌فای:**
   - تکنسین وارد تنظیمات وای‌فای شده و به مودم کارگاه یا هات‌اسپات گوشی متصل می‌شود.
2. **ورود رمز ۱۲۳ و دریافت متادیتا:**
   - لانچر ابتدا فایل `lastfile` ماشین انتخابی را در حافظه موقت دانلود می‌کند.
   - نام برنامه، شماره نسخه سرور (`V1.8.x`)، حجم فایل و هش SHA-256 نمایش داده می‌شود.
   - تغییرات نسخه جدید خط به خط (حداکثر ۱۳ کلمه در هر خط) به زبان فارسی به تکنسین نشان داده می‌شود.
3. **تایید و استریم باینری فریمور:**
   - با فشردن کلید **تایید / نصب**، دانلود فایل `firmware` در بافرهای ۱۶ کیلوبایتی آغاز می‌شود.
   - تسک شبکه در Core 0 اجرا شده و با تابع `esp_ota_write()` داده‌ها را مستقیم در پارتیشن فلش هدف می‌نویسد.
4. **اعتبارسنجی هش و سوئیچ پارتیشن بوت:**
   - همزمان با نوشتن، هش SHA-256 داده‌های دریافتی محاسبه می‌شود.
   - پس از اتمام استریم، هش محاسبه‌شده با هش ثبت‌شده در `lastfile` مقایسه می‌شود.
   - اگر هش ۱۰۰٪ منطبق بود، تابع `esp_ota_set_boot_partition()` اجرا شده و پارتیشن فعال به نسخه جدید تغییر می‌یابد.
   - در صورت عدم تطابق هش حتی در یک بایت، پارتیشن جدید ابطال شده و سیستم بدون تغییر باقی می‌ماند (جلوگیری قطعی از بریک شدن).
5. **راه‌اندازی مجدد و حفاظت از کالیبراسیون:**
   - دستگاه ریست شده و مستقیماً با فریمور ماشین انتخابی بالا می‌آید.
   - **نکته بسیار مهم:** پارتیشن NVS در آدرس `0x9000` دست‌نخورده باقی مانده و کلیه کالیبراسیون‌ها، تنظیمات پیشین وای‌فای و قفل‌های اقساط مشتری حفظ می‌شوند.

## ۴. قابلیت ورود دستی لینک OTA (Custom URL Installer)

در کارت اول لانچر (زیر عنوان HAFFLER HT-V3A)، یک دکمه تعبیه شده است که با فشردن آن کیبورد لمسی و کادر متنی باز می‌شود. تکنسین می‌تواند مستقیماً آدرس دلخواه HTTP/HTTPS یک فایل فریمور در شبکه محلی یا سرور خصوصی را وارد کرده و عملیات نصب را انجام دهد.
