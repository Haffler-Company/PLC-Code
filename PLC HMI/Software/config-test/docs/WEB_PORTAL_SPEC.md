# مشخصات فنی و معماری وب‌اپلیکیشن صنعتی لانچر و تستر (Web Portal Specification)
## Wireless Diagnostic Portal, SoftAP Management & Browser OTA — config-test

این سند تشریح‌کننده ساختار فنی، نقاط پایانی و معماری وب‌اپلیکیشن داخلی سیستم لانچر و تستر سخت‌افزاری هافلر (`firmware/include/app/web_portal.h`) است که امکان اتصال بیسیم از طریق گوشی هوشمند یا لپ‌تاپ را برای تکنسین‌های خط تولید فراهم می‌آورد.

---

## ۱. معماری شبکه و اتصال بیسیم

- **حالت اکسس‌پوینت داخلی (SoftAP):**
  - نام شبکه وای‌فای: `Haffler-ConfigLauncher-V1.8.x`
  - آدرس پیش‌فرض در مرورگر: `http://192.168.4.1`
  - اتصال مستقیم بدون نیاز به هیچ‌گونه اینترنت یا روتر خارجی.
- **حالت ایستگاه (Station Mode):**
  - اتصال به شبکه مرکزی کارخانه یا هات‌اسپات موبایل جهت ارتباط با سرورهای ابری OTA.

---

## ۲. فهرست نقاط پایانی وب‌سرور (REST API Endpoints)

| مسیر (URI) | متد HTTP | نوع محتوا | شرح عملکرد |
|:---|:---:|:---:|:---|
| `/` | GET | `text/html` | صفحه داشبورد مدرن تحت وب لانچر و تستر سخت‌افزار هافلر |
| `/api/hw_status` | GET | `application/json` | گزارش زنده وضعیت کلیه رله‌ها، دماها، ولتاژها، رم و بار CPU |
| `/api/test_relay` | POST | `application/json` | فرمان تست تحریک پالس ۳ ثانیه‌ای رله انتخابی از راه دور |
| `/api/test_ssr` | POST | `application/json` | فرمان تست موقت المنت‌های حرارتی با پایش سنسور دما |
| `/api/print_test` | POST | `application/json` | فرمان چاپ مستقیم تاییدیه QC به پرینتر حرارتی RS485 |
| `/api/scan_wifi` | GET | `application/json` | اسکن شبکه‌های وای‌فای اطراف و بازگرداندن فهرست SSID و قدرت سیگنال (RSSI) |
| `/api/connect_wifi` | POST | `application/json` | دریافت SSID و رمز عبور و اتصال به مودم کارگاه |
| `/api/flash_target` | POST | `application/json` | صدور فرمان شروع دانلود و فلش فریمور ماشین انتخابی از سرور |
| `/update` | GET / POST | `multipart/form-data` | فرم آپلود مستقیم فایل باینری فریمور از روی لپ‌تاپ تکنسین و فلش روی پارتیشن OTA |
| `/reboot` | POST | `application/json` | راه‌اندازی مجدد سیستم پس از ذخیره نهایی پارامترها |

---

## ۳. امنیت و قابلیت اطمینان صنعتی

- اجرای وب‌سرور سبک و ناهمگام (Asynchronous) بر روی هسته ۰ پردازنده (Core 0) به گونه‌ای که حتی در زمان تبادل سنگین داده با موبایل، نرخ فریم نمایشگر LVGL بر روی هسته ۱ (Core 1) هرگز زیر ۵۰ فریم سقوط نکند.
- کلیه دستورات تحریک سخت‌افزاری دارای تایم‌اوت‌های ایمنی سخت‌افزاری ۳ ثانیه‌ای هستند تا در صورت قطع ارتباط وای‌فای، هیچ خروجی یا المنتی روشن باقی نماند.
