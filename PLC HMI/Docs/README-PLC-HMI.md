# PLC HMI

پروژه PLC HMI پلتفرم HMI لمسی هافلر برای کنترل و مانیتورینگ چند کاربرد صنعتی است. این خانواده از ESP32-S3، نمایشگر TFT لمسی و LVGL استفاده می‌کند و در مخزن چند پروژه کاربردی مستقل برای آن دیده می‌شود.

## ساختار پوشه‌ها

- `Docs`: مستندات عمومی، دانش فنی، مرجع سخت‌افزاری و فایل‌های معرفی محصول.
- `Hardware/Main-V4.0.2`: برد اصلی مشترک.
- `Hardware/LCD-V4.1.1`: برد LCD/TFT، BOM و خروجی ساخت.
- `Software/libraries`: کتابخانه‌های مشترک مانند LVGL، TFT_eSPI، RTClib و MAX6675.
- `Software/Config_Plus_Test`: پروژه تست/کانفیگ و دانش فنی مرتبط.
- `Software/Gas-filling`: پروژه کاربردی پرکن گاز.
- `Software/Bakery`: پروژه کاربردی نانوایی/چونه‌گیر.
- `Software/Welder_single_head`: پروژه HMI جوش تک‌سر.
- پوشه‌های کاربردی خالی مانند `Aluminum-punching` و `Copy_router`: محل رزرو برای پروژه‌های آینده یا نیازمند تکمیل.

## مشخصات برداشت‌شده از مخزن

- پلتفرم نرم‌افزار: ESP32-S3، Arduino/PlatformIO، LVGL.
- رابط کاربری: TFT لمسی، تصاویر bitmap، فونت‌های سفارشی و چندزبانه‌سازی در بعضی پروژه‌ها.
- پروژه‌ها ترکیبی از سورس، خروجی build، باینری release و کتابخانه‌های vendor شده دارند.
- حجم این بخش نسبتاً زیاد است و بخش‌هایی مثل `.pio`، `build` و کتابخانه‌های تکراری باید قبل از انتشار عمومی بازبینی شوند.

## نکات نگهداری

- هر پروژه کاربردی داخل `Software` باید README مستقل شامل هدف پروژه، سخت‌افزار هدف، نحوه build، نحوه flash و نسخه کتابخانه‌ها داشته باشد.
- فایل‌های خروجی build نباید جایگزین مستندات release شوند؛ برای release فقط باینری‌های لازم، آدرس‌های flash و نسخه سورس کافی است.
- مسیرهای قدیمی داخل بعضی مستندات باید با ساختار فعلی `PLC HMI/Software/...` هماهنگ شوند.
- رمزها، SSIDها و کدهای اضطراری در صورت public شدن مخزن باید حذف یا با نمونه امن جایگزین شوند.
