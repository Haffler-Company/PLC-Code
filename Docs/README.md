# مخزن محصولات PLC شرکت هافلر

این مخزن برای نگهداری مستندات، طراحی سخت‌افزار، فیرم‌ور و فایل‌های مرجع خانواده محصولات PLC/HMI هافلر آماده شده است. هدف این ساختار این است که هر پروژه برای توسعه‌دهنده، تیم سخت‌افزار، تولید، خدمات و آرشیو GitHub قابل فهم و قابل پیگیری باشد.

## پروژه‌ها

| پروژه | کاربرد کلی | نمایشگر/رابط | سخت‌افزار موجود | نرم‌افزار موجود |
|---|---|---|---|---|
| [PLC 5K](PLC%205K/README-PLC-5K.md) | کنترلر صنعتی با رابط سون‌سگمنت، مناسب پروژه‌های جوش/فرایندهای ساده‌تر | 5 کلید / سون‌سگمنت | `Main-V4.0.2`, `DIS-V3.8.4` | `V4.6.0` |
| [PLC 8K](PLC%208K/README-PLC-8K.md) | کنترلر صنعتی با ورودی/خروجی بیشتر و نمایشگر کاراکتری | LCD کاراکتری / 8 کلید | `Main-V4.0.2`, `DIS-V3.0.2` | `V.2.7.0` |
| [PLC 10K](PLC%2010K/README-PLC-10K.md) | نسخه کامل‌تر خانواده سون‌سگمنت با پروژه اصلی و نسخه TuranTec | 10 کلید / سون‌سگمنت | `Main-V4.0.2`, `DIS-V.3.6.4` | `V.4.4.0`, `V.4.4.0 TuranTec` |
| [PLC HMI](PLC%20HMI/README-PLC-HMI.md) | پلتفرم HMI لمسی مبتنی بر ESP32-S3 و LVGL برای چند کاربرد صنعتی | TFT لمسی | `Main-V4.0.2`, `LCD-V4.1.1` | چند پروژه کاربردی مستقل |

## ساختار استاندارد

```text
PLC <Product>/
├── README-PLC-<Product>.md
├── Docs/
│   ├── KNOWLEDGE.md
│   └── فایل‌های دیتاشیت، عکس محصول و مرجع فنی
├── Hardware/
│   ├── Main-Vx.x.x/
│   └── DIS-Vx.x.x یا LCD-Vx.x.x/
└── Software/
    ├── Program Addres.txt
    ├── libraries/
    └── V.x.x.x/ یا نام پروژه کاربردی
```

## دانش فنی مشترک

- خانواده PLCهای 5K/8K/10K بر پایه ESP32 و Arduino Core نگهداری شده‌اند.
- خانواده HMI بر پایه ESP32-S3، نمایشگر TFT لمسی، LVGL و پروژه‌های کاربردی مستقل است.
- در چند پروژه از RTC نوع DS3231، ذخیره تنظیمات در EEPROM/NVS، WiFi AP داخلی، SPIFFS/LittleFS و آدرس‌دهی فلش ESP32 استفاده شده است.
- فایل‌های Altium شامل شماتیک، PCB، BOM و خروجی‌های ساخت هستند. برای مشاهده کامل سخت‌افزار به Altium Designer یا خروجی‌های PDF/HTML موجود نیاز است.
- خروجی‌های build، فایل‌های موقت، پوشه‌های `.pio` و فایل‌های cache نباید مبنای توسعه باشند و بهتر است قبل از انتشار عمومی پاک‌سازی یا با `.gitignore` کنترل شوند.

## وضعیت آماده‌سازی برای GitHub

این مخزن از نظر مستندات پایه آماده‌تر شده، اما چند مورد باید قبل از انتشار عمومی بررسی شود:

- وجود چند `.git` داخلی در زیرپوشه‌ها که باید حذف یا به submodule واقعی تبدیل شوند.
- حجم بالای خروجی‌های build، کتابخانه‌های vendor شده و فایل‌های باینری.
- وجود رمزها یا کدهای پیش‌فرض در بعضی مستندات/کدها، در صورت public شدن مخزن.
- نام‌گذاری ناهماهنگ بعضی پوشه‌ها مثل `V4.6.0` در مقابل `V.4.4.0` و `Program Addres.txt`.

جزئیات کامل در [FIXES.md](FIXES.md) ثبت شده است.
