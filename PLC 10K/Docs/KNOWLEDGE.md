# دانش فنی PLC 10K

این فایل دانش فنی فعلی PLC 10K را برای نگهداری، توسعه و آماده‌سازی GitHub خلاصه می‌کند.

## هدف محصول

PLC 10K نسخه پیشرفته‌تر خانواده کنترلرهای سون‌سگمنت/کلیدی هافلر است. وجود دو شاخه نرم‌افزاری `V.4.4.0` و `V.4.4.0 TuranTec` نشان می‌دهد پروژه یک نسخه عمومی و یک نسخه اختصاصی یا مشتری‌محور دارد.

## سخت‌افزار

- برد اصلی: `Hardware/Main-V4.0.2`
- برد نمایشگر: `Hardware/DIS-V.3.6.4`
- فایل‌های Altium شامل شماتیک، PCB، کتابخانه داخلی، BOM و خروجی ساخت هستند.
- پوشه `History` در سخت‌افزار فعلاً خالی است و اگر داده تاریخی ندارد می‌تواند حذف شود.

## نرم‌افزار

- نسخه اصلی: `Software/V.4.4.0/welding_7segment`
- نسخه TuranTec: `Software/V.4.4.0 TuranTec/welding_7segment`
- پلتفرم: ESP32 با Arduino Core
- وابستگی‌های دیده‌شده: DS3231، ArduinoJson، WebSockets و کتابخانه‌های داخلی.

## تفاوت نسخه‌ها

در حال حاضر تفاوت دقیق نسخه اصلی و TuranTec در مستندات سطح پروژه توضیح داده نشده است. برای آماده‌سازی حرفه‌ای GitHub باید مشخص شود:

- تفاوت عملکردی چیست؟
- برد هدف هر نسخه یکسان است یا متفاوت؟
- آیا فایل پروگرام، data و آدرس فلش متفاوت دارند؟
- آیا نسخه TuranTec عمومی است یا مخصوص مشتری و نباید public شود؟

## موارد نیازمند تکمیل

- README مستقل برای `V.4.4.0` و `V.4.4.0 TuranTec`.
- تعیین تکلیف `.git` داخلی داخل هر شاخه نرم‌افزار.
- تکمیل یا حذف `Software/libraries`.
- تولید خروجی PDF/HTML کامل سخت‌افزار برای مشاهده بدون Altium.
