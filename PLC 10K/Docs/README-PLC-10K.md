# PLC 10K

پروژه PLC 10K نسخه کامل‌تر خانواده کنترلرهای سون‌سگمنت هافلر است. ساختار موجود شامل برد اصلی `Main-V4.0.2`، برد نمایشگر `DIS-V.3.6.4` و دو شاخه نرم‌افزاری `V.4.4.0` و `V.4.4.0 TuranTec` است.

## ساختار پوشه‌ها

- `Docs`: محل استاندارد دیتاشیت، عکس، مستندات فنی و دانش پروژه.
- `Hardware/Main-V4.0.2`: برد اصلی شامل شماتیک، PCB، BOM و خروجی ساخت.
- `Hardware/DIS-V.3.6.4`: برد نمایشگر/کلید PLC 10K.
- `Software/V.4.4.0`: نسخه اصلی فیرم‌ور `welding_7segment`.
- `Software/V.4.4.0 TuranTec`: نسخه اختصاصی/مشتق‌شده برای TuranTec.
- `Software/libraries`: محل استاندارد کتابخانه‌های مشترک؛ در حال حاضر خالی است.
- `Software/Program Addres.txt`: آدرس‌های پروگرام و فلش.

## مشخصات برداشت‌شده از مخزن

- پلتفرم نرم‌افزار: ESP32 با Arduino Core.
- نوع رابط کاربری: سون‌سگمنت و کلیدهای فیزیکی.
- کتابخانه‌های دیده‌شده: DS3231، ArduinoJson، WebSockets و وابستگی‌های داخلی پروژه.
- دو نسخه نرم‌افزاری باید از نظر تفاوت عملکرد، مشتری/کاربرد و سازگاری سخت‌افزار مستند شوند.

## نکات نگهداری

- `V.4.4.0 TuranTec` بهتر است README اختصاصی داشته باشد تا تفاوت آن با نسخه اصلی روشن شود.
- پوشه `Hardware/DIS-V.3.6.4/History` خالی است و برای GitHub ارزشی ندارد مگر اینکه خروجی تاریخی در آن قرار گیرد.
- فایل‌های `.git` داخلی در نسخه‌های نرم‌افزار باید قبل از push تعیین تکلیف شوند.
